# 2.2课前编辑简报

起草前编制，2026-10-30；PY101 / PY101-C02 / PY101-C02-L02，必学r1。沿用V1.0与P7蓝图。

读者已完成第一章和2.1，会合法命名、字符串引号、赋值/重新赋值、print名称/文字、预测、保存完整运行.py。核心问题：**为什么两个值在屏幕上看起来都是3，Python却可能把它们当作不同类型的数据？**

真实补修：2.1#name-and-value、#literal-or-name、#predict-run；1.3#save-rerun。观察工具import/sys等不是学生自写先修。本课首次系统引入类型、str/int/float/bool基本字面量、True/False大小写、type单参数观察与嵌套print的先后、同名绑定不同类型的值。

三项正式目标：①按文字标记、完整件数、测量值与真假状态的用途，独立选择基本字面量、赋值并简述理由；②在真实.py中使用type取得四类型证据，解释相同显示不代表相同类型；③同名先后绑定整数/数字文本，先预测类型再运行，换新数值重跑并解释名称与当前值的关系。

主例按阶段构建：先两值都打印3→介绍int与str区别→1.5测量值及float精度边界→True/False状态与"True"文字→先解释type嵌套，再观察→完成P7四类12语句主例→同名8/"8"重绑定→两道短新题。预测先于输出框/运行；预期见PRE_SOLUTIONS，真实运行另存。

无需图片或下载。核心不使用input、显式类型转换、四则/比较、if/循环、容器、函数/类定义、isinstance、类型标注、文件或第三方库；不展开浮点二进制/精度运算、bool/int继承。没有可选区暗藏达标先修。

中文难点：数字字符与数值混淆；把type当转换；嵌套括号不知先后；把<class 'int'>当HTML或源代码；误说“变量名的类型永久固定”或“旧整数变成字符串”。逐次用显示/类型两份证据解释，避免堆术语或警告清单。

阅读12–18、练习6–10、代码12–18分钟，共30–46，basis=editorial-estimate。保留蓝图估计；安装/权限/设备故障另计。独立任务长度及类型首次解释负担待学生观察，不据字数冒充实际耗时。
