## 3. 相比2.1的新知识

从“名字当前对应哪个值”接到“这个值属于哪种类型”。整数3与文字"3"普通显示都为3，不能据此判断类型；type读取当前值，print显示取得的类型。同一名称先绑定整数，再绑定数字文本，读到的类型随当前值不同，名称不固定决定类型。正文不提前教授转换、表达式运算、比较或控制流。
