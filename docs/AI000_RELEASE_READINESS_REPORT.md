## 4. 教师审稿包与定位

[准备包入口](ai000-release-readiness/README.md)和24个`lessons/AI000-Cxx-Lxx.md`均可直接开始取阅。逐课列学习目标及真实映射、完整先修和补修路径、具体事实/争议检查点、每个section及图/表/计算定位、每题两级提示、全部解答/rubric固定源码块、合理替代方向及空白签署位置。每条GitHub源码链接固定到同一完整教材SHA，具体行范围由TypeScript AST定位，区分section/题目同名；不是浮动main链接。

[REVIEW_CATALOG.json](ai000-release-readiness/REVIEW_CATALOG.json)记录24课定位、完整对象SHA-256、目标和题目计数。正式源码是唯一来源：不复制24份教材。原rubric全文汇总在[ASSESSMENT_RUBRIC.md](ai000-release-readiness/ASSESSMENT_RUBRIC.md)，完整答案可直接打开固定源码块，或用`--show-task`在核验快照后展开本课讲解/题设上下文和指定题全部答案，避免漏掉跨section的资料；不生成另一套可漂移的标准答案。

[SUBJECT_REVIEW_TEMPLATE.md](ai000-release-readiness/SUBJECT_REVIEW_TEMPLATE.md)要求专业人员亲自重新求解，写准确原文、核验过程、误解机制、目标影响、阻断与否、替代解和整改复核。第3/4章重点定义/题设/推导/计算，第5章任务与方法，第6章事实/隐私/公平/许可及法律边界，第7章依赖/可行里程碑/报告效度。超出专长的事项转适任者，不能由AI签署通过。

每课链接manifest当前技术报告，也链接实际最初开发/当时交付报告，并注明旧报告只适用其当时版本。历史旧状态/旧学时不覆盖固定现稿，也不把历史AI辅助报告当专业审核。

## 6. 真实试学协议与记录

[PILOT_PROTOCOL.md](ai000-release-readiness/PILOT_PROTOCOL.md)区分13节优先单课深度试学和完整24节路线。前者覆盖基本概念、范式、数据模型、应用、责任及规划/综合，不能推全程完成率或免除其余11节专业审核。完整路线需同一学习者实际走完与记录；未做继续待办。
