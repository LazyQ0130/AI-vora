## P6：另开核验轮的概念、图与答案复核

核验者仍为同一 Codex。离开写作结论，先从描述列出“判断关系从哪里来”“采用什么结构”“输入输出承担什么任务”，再对照实际注册稿的参考解。没有把它称为专业独立人工审稿，也没有让 AI 自评分。

| 对象 | 重新核验与结果 | 接受范围 / 限制 |
| --- | --- | --- |
| ML | 从例子学得判断关系，已有模型用于新输入；学出的树运行时也可执行条件分支 | 不能把运行时“有规则”当作排除 ML 的证据；没有声称所有 ML 都靠已标注类别 |
| DL | 多层计算学习表示与组合，因仍从数据学习而属于 ML | “边缘到形状”限于某些视觉网络的直觉，不把每层硬指定为眼睛、耳朵；未声称 DL 总更准或免数据处理 |
| AI / ML / DL 图 | DOM 中 ML 元素确实在 AI 内、DL 在 ML 内；外部区域分别保留知识推理和普通决策树例子 | 图中范围是本节简化后的三层，并非穷尽 AI；面积不代表数量、性能或历史阶段 |
| 生成任务图 | 同一已知 DL 方法，分别承担“照片→类别”和“描述→新图像内容” | 两侧方法由题设给出；无“生成式 AI 是唯一第四层”的图，也不从文件格式反推方法；内容以文字示意，未伪造模型生成实验 |
| 生成式 AI / LLM | 对照 NIST 能力描述、Google 术语及教材的方法关系，分别记录任务与方法 | 现代常见生成式 AI 大多使用 DL 是范围限定的表述；历史生成模型和今天产品用语不完全相同；LLM 可用于分类，生成类别文字不等于创作任务 |
| 图一练习 | 从三个区域重新构造：纯知识推理→AI；学得普通树→AI/ML；深度网络→AI/ML/DL | 学生自拟例子须提供支持位置的方法信息；同功能可以选不同方法，产品名不能代替证据 |
| 分类题甲 | 纯人工知识规则组合现象，且明确无数据学习→AI；任务为故障原因推断 | 排除 ML/DL 有明确题设条件；不据规则固定就排除 AI，不假定诊断一定正确 |
| 分类题乙 | 从带品种记录学普通树且不用神经网络→AI/ML、非DL；任务为花品种分类 | 新场景输入是测量数值，并不要求学生学树的训练算法；性能未知 |
| 分类题丙 | 已训练深度网络→AI/ML/DL；根据文字要求产生新海报→图像生成 | 不能只写“生成式”而漏掉已知方法；具体网络结构、效果和授权状况没有给出 |
| 分类题丁 | 仅宣传语不能确定具体任务或方法 | 接受条件性回答但必须写条件；追问输入输出与实现。补充“会生成海报”后仍不能确定 DL，还需确认是生成、检索还是套模板 |
| 分类题戊与比较 | 训练出的深度网络→AI/ML/DL；录音→“门铃”类别，属于分类 | 不能因为输出文字就认定在创作内容；不能推定它另有音频合成能力。与丙共同检验目标2 |

两题均有两级渐进提示：第一级给思路，第二级提供中间线索；解答逐项解释成立理由，另有常见错法与 rubric。图题要求学生自行生成关系与例子，分类题换为家电、花朵测量、节日海报、宣传语和声音，不只是复述猫图。目标1由画图解释检验，目标2由丙/戊和丁补充信息检验，目标3由五项证据及未知信息检验。映射存在和同一工具复核均不能证明真实迁移有效性。

两张图均为原创受控 HTML/CSS 文本与边框，没有复用第三方图片、代码或数据。第一张解释集合包含，第二张解释方法与任务，教学目的不同，故都保留。figure 通过 aria-describedby 关联解释性 alt，通过 aria-labelledby 关联图注；信息不只靠颜色表达。桌面两列对照，手机顺序阅读两张卡。实际新图文字14–18px，正文16px、图注14px；最窄320px也没有图内或整页横向溢出。本轮没有发现需要扩大为 UI 修复的问题；未做真实读屏软件测试。
