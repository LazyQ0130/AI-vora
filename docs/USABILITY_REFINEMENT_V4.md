# 手机可读性与无障碍修正 V4

核查日期：2026-10-25。基于用户列出的十项问题，先实测后修复；不改变课程资料与前端演示边界。

## 实测与修复

| 项目 | 核查结果与最终行为 |
| --- | --- |
| 手机字号 | 390px 原课程目标 10px、学时 9px、先修 8px、品牌副标题 6px，确实偏小。现课程目标 14px，学时/先修/状态/品牌副标题 12px；阅读正文 15px，章节抽屉目录 14px。装饰性英文仍单独使用小字号。 |
| 手机学习路径 | 原双列课程节点改为单列阶段步骤条，同阶段课程在阶段内纵向分组。桌面保持依赖关系图。阶段标签使用中性的“同阶段课程”，原有并行与补修说明保留，避免把同阶段误解为全部无先修依赖。 |
| 点击区域 | 等级按钮和菜单至少 44×44px；搜索输入区域高 46px；阅读顶部按钮高 44px，内容标签高 48px，章节链接约 44.6px。等级筛选可换行，不再缩小按钮。 |
| 可读样章 | 新增共享样章索引，只为 ML201 提供“含可阅读样章”的直达入口。课程卡使用独立的标题链接与样章链接，避免嵌套链接。路径节点突出样章入口，并将重复的“规划中”改为“查看课程”；页首与说明仍明确整门课程尚在规划。 |
| 对比度 | 统一 `--text-supporting`、`--text-secondary`、`--text-code-comment` 等令牌。Prism 注释主题引用同一注释令牌，避免行内主题颜色覆盖 CSS。 |
| 封面比例 | 手机课程目录使用简洁图标封面条，紧凑阅读缩略图也使用独立图标，不缩小完整信息图。首页宽幅课程封面保留准确的 SVG 内容层；详情侧卡使用独立 16:9 比例，手机侧卡改为纵向布局。 |
| 学习中心 | 统计卡改为两列加一张通栏；标题与图标始终位于同一行。说明文字至少 12px，阅读记录内容使用独立的手机布局。 |
| Ctrl+K | 跨页面通过临时 `focus=search` 标记进入课程页、聚焦并选中搜索框，再清除标记。同页直接聚焦并选中当前搜索词，保留查询与筛选。Windows 显示 Ctrl K，Apple 平台按检测结果显示 ⌘ K。 |
| 可访问名称 | 品牌使用完整自然文本名称；搜索链接名称包含可见“探索知识 Ctrl K”及搜索说明。实际可访问名称检查已通过。 |
| 公式语义 | 四个可横向滚动的公式区域均使用 `role="region"`、可访问名称和键盘焦点，保留 KaTeX MathML。 |

## 验证记录

- `npm run typecheck`、`npm run lint`、`npm test`、`npm run build` 全部通过，共 11 项测试。新增样章索引回归测试，防止为未提供教材的课程生成入口或把整门课程标记为发布。
- 使用构建后的本地版本在当前 Chromium 浏览器实际检查：首页、课程目录、ML201 详情、路径、学习中心、阅读页 × 320 / 390 / 768 / 1024 / 1440px，共 30 组。无页面横向溢出、破损图片和嵌套链接。
- 实际键盘验证：从首页按 Ctrl+K 进入课程搜索；搜索 ML201 后再次按 Ctrl+K，焦点仍在搜索框且选中 5 个字符，查询保持不变。另验证了页头搜索链接的聚焦行为。
- 实际点击验证：ML201 样章入口直接打开阅读页；内容标签跳转后标题位于吸顶栏下方；手机章节抽屉跳转后关闭面板、更新锚点、聚焦正文标题，当前导航正确。公式标签检查中导航下缘约 183px，目标标题约 233px，无遮挡。
- 最终浏览器未记录 error / warn。截图使用系统减少动态效果模式，避免动画中间帧；该模式下的布局与焦点行为均已检查。

## 设计取舍与边界

功能文字尺寸优先于卡片密度，因此手机卡片不再使用窄栏正文，先修要求允许换行。完整课程仍全部处于规划阶段，只开放一节原创演示样章；没有新增后端、登录、支付、视频、AI 助手或 AI API。原始课程文件、参考图和提供的设计令牌文件保持原样，新增的功能令牌集中在 `src/app/usability.css`。

此次验证覆盖当前 Chromium 的桌面及响应式视口，未执行触屏真机、其他浏览器或完整读屏器测试，不代表完整 WCAG 认证。Apple 快捷键显示分支已实现，未在 Apple 真机验证。专业人工教材审校与试学仍沿用既有待办。
