# 3.2 教学与中文复核

按V1.0、P15新手编辑原则和P16当前r1先修审读。此为Codex工具辅助另一轮检查，没有冒充独立教师/中文编辑，也不以自评分或字数变化推断教学效果。

| 原表达/设计与位置 | 具体理解风险 | 本轮表达或保留决定 | 可观察任务 |
| --- | --- | --- | --- |
| 从3.1程序开始（single-if） | 直接多分支会让else缺少用途 | 保留单if已有语法，先让7件只显示结束，再提出超限提示需求 | 学生指出原来缺少哪条动作 |
| else后再给完整两路（two-ways） | 以为else写自己的条件，或两个块都执行 | 代码前先解释真假、互斥、else:无条件、同层及4空格，块外结束独立 | 自写两路并实跑真/假，等值结合<=解释 |
| elif首次出现（three-ways） | 将elif当第二个独立if，或不知道为何两路不够 | 先提出少/等/超新需求，再解释elif的条件、冒号、顺序，然后展示完整代码 | 三轮各一条分类，能逐项说明实际检查 |
| “6==6也成立”（first-match） | 把表达式成立等同本轮已求值 | 明确首项<=真后，第二比较未实际执行；只改<再跑等值 | 预测Within limit→At limit的最小对照 |
| 题二标题最初按交接描述“互相冲突的提示” | Within limit和At limit可以同时是正确事实，称为逻辑冲突会误导 | 改称“两条分类提示”，解释问题在唯一分类业务要求；保留多个独立if可用于独立事实 | 判断任务需要独立事实还是唯一分类 |
| 题一两路参考早期标签Seats available | 可能被读成仍有空位，与<=包含坐满混淆 | 改为Enough seats，与Not enough seats成对；三档才用Spare seats/All seats taken/Need more seats | 解释两路与三路问的问题不同 |
| 两阶段任务 | 记录减负时可能把旧输出当新版结果 | 一份源码加差异；两路2轮、三档3轮各自实跑，命令/环境一次复用 | 检查阶段版本与实际结果对应 |
| 独立if改链（practice） | 只把第二if换elif仍让<=遮住等值 | 提示检查范围/顺序，参考解释结构和第一条件都要对照规则 | 修前重复、修后低等高分类，不能删print凑结果 |
| 重叠观察副本无结束print | 可能把缺少结束输出误认为链让程序停止 | 在该短例前交代副本只观察选择，完整主例与两题均有块外收尾 | 学生按实际源码预测，不凭固定输出记忆 |
| 图、参考、出版说明 | 装饰图、长报告或出版术语会分散注意力 | 零图/下载；源码对齐+短边界表已精确表达归属；完整参考使用既有verification，核心首次知识均在正文 | 无提示先自己写，再展开自查 |

正文正常路径先于重叠诊断，关键误解各有一次最小可运行对照；没有给每个预测增加长分析。九个section围绕实际学习过程形成，未按固定H2数量凑稿。正式三目标与两题对应，双提示不给完整程序/数据，解答含原因、常错、合理替代和真实证据要求。正文只用顶层if链/单比较，无逻辑组合、循环、嵌套、容器或函数定义。

3.1不改：完整r1对象、Publication与scope和本轮基线相同，其“下一节学习else与多路选择”仍准确；第一、二章r2正文也不改。P0–P16和P15固定r2审阅包保留，不继承为本轮已审。
