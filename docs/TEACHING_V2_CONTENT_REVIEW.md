## 贯穿案例与术语约定

虚拟传感器校准：输入和目标均为**无量纲合成刻度**，不是采集到的真实设备数据。3.1–3.3 使用 (0,1)、(1,3)、(2,5)；4.3/4.4 明确只选后两个点，以减轻手算负担。w 是斜率、b 是偏置、ŷ 是预测、y 是观测目标；误差统一为 ŷ−y。n 始终为样本数。损失统一为完整 MSE=(1/n)Σe²，没有 1/2。

输入、目标、参数的角色先讲清，再定义公式；3.3 先逐点求误差再讲聚合；4.1 用单变量差商说明局部方向，4.2 才引入两个偏导与链式法则。Hessian、特征值收敛上界不进入新版主线。旧综合样章中的进阶材料原样保留，以兼容书签。

## 数学与程序独立验证

1. 用 Fraction 核对 MAE=5/3、MSE=11/3；候选 w=b=1 的 MSE=5/3。
2. x=[1,2]、y=[3,5]，w=b=0：dw=−13、db=−8、MSE=17。η=0.1 同步更新为 (1.3,0.8)，新误差 [−0.9,−1.6]、新 MSE=1.685。
3. 新 w 下重算 db 得 −4.1、b=0.41，最终 MSE=2.8121；忘记平均得到 (2.6,1.6)、MSE=2.34。两种错误都可能下降，故不能以“下降”作为唯一正确性判断。
4. 3 个不同参数点用中心有限差分核对两个解析梯度，h=1e−5、绝对容差 1e−8、rtol=0。重复样本后，平均损失梯度不变。
5. NumPy 默认 2000 步结果与独立最小二乘解比较，参数 atol=1e−7、rtol=0；最终 MSE<1e−10。首步与手算比较 atol=1e−12。历史长度 2001，全部有限。
6. 200 步比较：η=0.01 得 (1.921161,1.127561)、MSE≈0.00164044；η=0.1 得 (1.994416,1.009035)、MSE≈0.00000823。仅在相同数据和预算下作结论，未声称通用最优步长。
7. 二维列向量、空数组、长度不一致、NaN、Infinity 均明确拒绝；有效一维输入通过。5 组脚本与 Notebook 同源，Notebook 无伪造输出。

实际 Python 版本 3.14.2，NumPy 2.5.2；13 项 Python 单元测试、15 个网页 Python 块均执行通过。详细 stdout/stderr 见 [执行证据](TEACHING_V2_PYTHON_RESULTS.json)。未仅凭静态阅读代码宣称运行正确，也未声称已测试所有 Python 3.10+ 版本。
