# AI000 人工审稿与试学准备包

教材审核基线：`fc30c72d5572bea05bafd9f9b5b55a54150d634b`（2026-10-29）。采用[编辑规范V1.0](../COURSE_EDITORIAL_STANDARD_V1.md)、[工程指南](../COURSE_AUTHORING.md)和[生产工作流](../COURSE_PRODUCTION_WORKFLOW.md)；V1.1建议稿不作为要求。本包准备了执行材料，没有开展人工审核或学生试学。

当前24节、72目标、49核心任务均有正文和映射；各课pending-review/preview，整课planned。850–1280分钟是编辑估计，原规划6–10小时保留。不存在教师签署、学生成绩或实测耗时。

## 从这里开始

1. 维护者指定有相应专长的学科教师、中文教学编辑、试学组织者、资料保管人与发布决策者。名单和安排在实际执行台账填写，本包不代填。
2. 打开[24节审核矩阵](REVIEW_MATRIX.md)，按课进入[逐课材料](lessons/AI000-C01-L01.md)。每课列目标/先修、事实/图表计算定位、每题两提示、完整解答/rubric源码块、替代答案待核方向、历史技术报告和空白签署位。
3. 教师复制[学科审核表](SUBJECT_REVIEW_TEMPLATE.md)，编辑复制[中文教学编辑表](EDITORIAL_REVIEW_TEMPLATE.md)。逐项留原文证据、误解机制、目标影响和处理理由；[49题原rubric](ASSESSMENT_RUBRIC.md)供核对，不按一个总分自动放行。
4. 汇总到[问题登记](ISSUE_REGISTER.md)。先处理已确认阻断，再进行[学生试学协议](PILOT_PROTOCOL.md)；使用[匿名空白记录](PILOT_RECORD_TEMPLATE.md)保存逐级帮助轨迹和[计时事件表](TIME_EVENT_TEMPLATE.md)。
5. 按[学时校准方案](TIME_CALIBRATION_PLAN.md)分析分项时间、重复产出和必要难度。按[发布门禁](RELEASE_GATES.md)由维护者核实际版本证据决定；下一步依赖见[NEXT_ACTIONS](NEXT_ACTIONS.md)。

## 固定版本与取阅

逐课GitHub链接均指完整教材提交，不链接浮动main作为审稿依据。参考答案不在旧报告中另找；正式源码为唯一内容来源，索引只复制短提示和原rubric，不复制24份长正文。[REVIEW_CATALOG.json](REVIEW_CATALOG.json)记录准确源码行范围和完整对象摘要，[CONTENT_SNAPSHOT.json](CONTENT_SNAPSHOT.json)固定47个教材对象、全部发布清单、课程状态及252个源码/课程事实/资产的Git blob。

如需易读全文，可在该提交的**单独干净检出目录**运行项目现有预览，使用`/learn/AI000/<lessonId>`；不要重置有个人改动的工作区。当前网页仅供便捷阅读，审稿者先核对服务所用提交；看起来相同的标题/r号不能证明是同一稿。

现有Node依赖可用时，先在仓库根目录执行：

```powershell
npx tsx scripts/prepare-ai000-release-readiness.ts
npx tsx scripts/prepare-ai000-release-readiness.ts --show-task AI000-C04-L01 build-print-records
```

默认命令只读，核验固定内容、定位、24/72/49、版本/状态和空白人工字段。`--show-task`也先核快照，再输出该课全部讲解/题设上下文及所选题的完整提示、答案、错因和rubric（不输出其他题答案）；这样不会遗漏跨section提供的资料。`--read-lesson`/`--read-chapter`仅供开发者通读当前对象，不作为绕过版本校验的教师入口。

`--generate`仅显式生成本包的派生索引/矩阵/rubric/时间表，初始快照和人工空态文件独占创建，不修改课程、发布状态或进度。它不适合承载真实人员结果。内容改动后校验会拒绝沿用本包；维护者另建绑定新提交的材料与执行台账，保留旧包。仅文档新增的后续提交可以仍引用未变的教材基线。

## 真实记录怎样交接

[HUMAN_REVIEW_STATUS.json](HUMAN_REVIEW_STATUS.json)是本轮“未开始”的冻结起点，意见/人员/分数/日期/结果均为空。真实执行时将模板复制到组织者事先确定的受限保存位置，并建立另一份执行台账，记录课时/r版本/完整SHA、记录ID、当前进展和证据引用；保留原起始文件。真实签署、处理和复核只由亲自执行的人填写。不要反复运行生成器覆盖人工意见。

可复制REVIEW_MATRIX作为执行台账，依据真实进展更新“未开始/进行中/完成”，每个完成项附适用版本的实际记录引用。未来真正推进Publication状态也会触发本包的冻结快照差异检查；维护者应区分纯状态推进与教材内容改变，分别留执行证据，不因守卫报差异就自动否定对同一正文已发生的真实审核。

本仓库可能公开。学生答案、录音、原稿和可识别信息默认不入库，不上传GitHub附件；随机编号不保证无法重识别。公开材料只放经保管人检查的必要去识别汇总和版本证据目录。保存地点、访问角色、保存期限/复查点、退出请求方式由组织者在招募前落实；未落实不采集。录屏、录音和保留完整原稿另行告知确认，拒绝不影响以文字方式参加。本轮没有招募、联系他人或收集任何参与者数据。

## 本包能证明什么

材料覆盖与技术检查可以复核；学科正确性、中文教学质量、学生独立表现和时间校准仍需真实人员执行。已有技术证据见[7.3交付报告](../AI000_LESSON_7_3_AND_COURSE_REVIEW.md)及[本轮报告](../AI000_RELEASE_READINESS_REPORT.md)。文件存在、AI审读、截图、点击已读或看完参考答案都不能替代发布证据。
