# 全课程学时与负担核查方案

当前没有学生实测。原始curriculum为6–10小时（360–600分钟），当前24节编辑估计850–1280分钟（14.2–21.3小时）。两者是不同阶段/范围的规划信息，不能把后者压回前者或把原事实覆盖掉。本轮不调整学时、不删关键题，也不声称用字数换算完成校准。

## 实际采集与分析顺序

1. 招募前冻结每课SHA/r、时间定义、计划人数/覆盖与先修分层，不看结果后才选择有利分母。单课和完整路线分别收集，未完成、退出和帮助保留。
2. 逐人逐课核事件不重叠、帮助阶段对应、核心与可选不混合；记录哪些时间缺失、是否复述后补记。复杂度差异与设备障碍分开解释。
3. 每课报告匿名样本数、完成到哪里、原始分项范围；样本适合时给中位数/分位数并列n及缺失。样本太小先列个案和范围，不报虚假的稳定分位数或总体完成率。
4. 将reading、practice合计、7.3project分别与相同口径的编辑区间比较：实际值减下限/上限，落在内/高于/低于；有充分数据后再给比例。不把“无提示”子项单独与含自查的完整practice预算比。
5. 按必要先修、是否首次暴露、帮助/补讲、单课/全程、分次与设备条件分层。基础差异不能解释成个人能力标签；小组差异不能未经控制就归因于某因素。
6. 完整路线只汇总同一学习者24课的真实事件和报告，另列前课补修/回读、总日历跨度及未完成。单课样本的中位数相加只能作编辑分析，不能当真实全程时间或完成率。
7. 教师/编辑对“耗时长且目标未达”“耗时长但必要迁移”“书写多、思考早已完成”等情况分别取证，决定解释补充、题干澄清、格式简化、分次安排或合适分层。每项建议绑定原目标、损益和重试范围。

## 依据实测调整与公开说明

若实测支持改变预算，维护者先审覆盖、版本与未完成偏差，再更新唯一学时表、课程规划说明及相关界面/README；保留本次850–1280与原curriculum6–10历史记录。公开说明区分“原规划”“当前编辑预计”“某版本/某先修范围下的实际观察”，同时说明提示/报告和可选活动口径；不把小样本中位数变成人人可完成的承诺。

仅改估时与说明、无任务实质变化时，可按版本规则记录为何维持r；若删/合核心任务、改变达标标准或移动核心到可选，应同步Lesson/manifest内容版本、保留旧进度键并重新核目标与受影响试学。涉及完整路线结构调整，先确认课程事实与维护者授权，不能为迎合6–10小时批量删题。
