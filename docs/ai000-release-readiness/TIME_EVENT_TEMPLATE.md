## 归类规则

- 同一时间只有一个活动和一个预算桶；下一事件开始不得早于上一事件结束。切换任务、帮助阶段、休息或设备故障时结束当前段。时长=结束−开始，未知时记缺失及原因，不能补猜。
- reading：正文/主例首次阅读及相应理论思考；固定题题干首次阅读可以随其练习一起归practice，但同轮必须一致并注明口径，不能两边都计。
- practice：普通固定题的题干、独立思考/作答、提示阅读及答案/rubric自查。活动think/answer/hint/selfcheck可拆观察，合计仍是一份practice，不额外再加“提示时间”到整份练习预算。
- project：7.3个人选题、三短析/比较、优先八问/两例、地图、路线、结论、相关资料阅读、提示/自查和复制保存。报告首次要求在阅读时已计的部分不重计；开始实际写报告后的活动都留本桶。固定场地题属于practice，不归project。
- coding：只有实际代码实践才用。AI000现稿强制代码0；Markdown报告模板不用执行。学习者自行扩展编程另记可选活动，不把它加进核心路线估时。未来增加代码先绑定新版本和预算。
- excluded：休息、环境/导航故障等待、组织者补讲、先修补修分别记活动与原因。独立活跃时间不含这些；另报含补讲/补修的现实投入，不能把它们藏掉以显示教材更快。

保留思考与书写分项，帮助判断难度来自概念还是冗长表达；它们是活动维度，不再与预算桶的总数相加。完整路线的回读/补修单列来源课和原因，先按以上口径报告独立学习与额外支持两种投入。
