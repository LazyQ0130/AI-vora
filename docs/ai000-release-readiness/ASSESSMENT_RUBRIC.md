## AI000-C07-L03 / write-personal-capstone

r1；目标 1「独立分析现实问题的需求、使用者、输入与输出，判断是否需要AI，说明可行任务与方法及现有资料不能确认的事项」；2「为明确问题提出有依据的基线、数据或学习信号、可执行评价与错误处理，检查相关隐私、来源和使用责任并安排补查」；3「比较三个自选问题并确定优先项目，形成含技术地图、至少三个可验证学习里程碑和适当结论范围的完整报告」。

[完整题干、提示、参考、错因与rubric](https://github.com/LazyQ0130/AI-vora/blob/fc30c72d5572bea05bafd9f9b5b55a54150d634b/src/content/lessons/ai000/problem-analysis-capstone.ts#L145-L175)；[逐课包](lessons/AI000-C07-L03.md)。

1. A 任务清晰：三个自选问题各有使用者/价值、实际输入输出和范围；优先问题含两个自拟小输入、预期及依据，一例体现缺失或变化。
2. B 选择有据：各说明AI必要性和简单办法；优先方法由任务/条件支持，学习信号有来源，不适用不强加；三问题比较及后置/重选理由成立。
3. C 条件真实：已有、假设、待取得的数据/权限/输出分开，缺项有具体补查，未伪称真实模型或系统已运行。
4. D 评价可执行：优先项目有对照、范围、具体核查/错误影响与独立检查安排，明确当前不能证明什么。
5. E 责任相关：针对该项目处理事实、隐私、覆盖/偏差或许可/使用条件，给复核角色与错误后的动作，不泛填‘注意安全’。
6. F 路线有依赖：至少三里程碑逐项写目标、基础、动作、成果、检查、继续与失败补修，先学/并行/暂缓有任务理由。
7. G 成果可核查：六部分组织清楚，技术地图区分任务/方法/普通软件或产品工作/数据评价，其他两问题简析足够，无需同等工程深度。
8. H 结论有边界：已确认/仍未知/下一动作能回到前文，未把模板、AI文档、展开答案或已读当掌握；自行复制保存，不需真实开发或训练。

合理替代方向（待教师核对）：任意有依据的三现实需求、普通软件或合适AI方向、不同文字布局和顺序均可；两自拟例、八问、地图、三里程碑与结论不能只换名称。
