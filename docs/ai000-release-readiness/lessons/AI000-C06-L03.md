## 学习目标与先修

1. 根据作品的具体用途和传播渠道，逐项核查素材来源、有权许可者与使用条件，区分可按条件使用、范围不符和证据不足的情况（核心题：audit-recruitment-assets）
2. 审查AI辅助作品中的事实、机构认可与人物声音使用，指出具体误导和待核依据，写出不增加无据承诺的完整修正版（核心题：review-lecture-release）
3. 为新作品制定素材处理、补查与人工复核清单，明确最终版本和渠道的发布决定，并安排传播后的逐项纠错（核心题：audit-recruitment-assets、review-lecture-release）

## 核心概念、事实与争议点

- compare-licenses：BY4可商用与NC用途限制、署名/改动/保留说明、其他权益和适用地区界限；法律疑点另请适任者复核。
- handbook-task：逐素材逐渠道，摄影许可不代人物公开/广告依据；未知不直接判违法。
- lecture-task：活动批准与官方背书分开，文稿/声音/最终成品及三渠道纠错，未发布假设不写成实绩。

这些是审查问题，不是已发现错误或人工审核结论。教师应亲自定位原文、重算数据/图示，指出误解机制、目标影响与阻断判断。

### audit-recruitment-assets · 交一份按用途作决定的素材审查表

核心位置 `handbook-task`；目标 1、3；[完整题设/两级提示/全部10步解答与4项rubric](https://github.com/LazyQ0130/AI-vora/blob/fc30c72d5572bea05bafd9f9b5b55a54150d634b/src/content/lessons/ai000/responsible-ai-use.ts#L105-L133)。

提示一（当前稿）：先把两个发布用途分别写在纸上，再逐项连接候选素材；“来源知道了”和“这个用途允许吗”留两栏。

提示二（当前稿）：任选一项，把准备执行的复制、修改、传播动作，与来源卡中明确允许的动作一一对应。圈出没有对应依据的那一格，写应向谁取得什么；再给最终文件留确认者、版本和渠道三格，其余素材仍需自己判断。

合理替代答案的待核方向：可不用音乐、替换清楚范围素材或只完成招新版本；不得虚构同意，实际标注与渠道复核要落实。

完整展开：`npx tsx scripts/prepare-ai000-release-readiness.ts --show-task AI000-C06-L03 audit-recruitment-assets`

### review-lecture-release · 交完整修正版与有负责人接手的发布清单

核心位置 `lecture-task`；目标 2、3；[完整题设/两级提示/全部10步解答与5项rubric](https://github.com/LazyQ0130/AI-vora/blob/fc30c72d5572bea05bafd9f9b5b55a54150d634b/src/content/lessons/ai000/responsible-ai-use.ts#L139-L168)。

提示一（当前稿）：给文字主张、谁在背书、准备怎样用声音各留一栏；一项事实正确不会让其他栏自动通过。

提示二（当前稿）：选一句宣传，先找题设中直接对应的资料，圈出不能由它支持的部分。修改后再用原资料检查所有必要信息是否还在；沿“文稿—实际成品—发布位置”分别留一个待确认项与接手角色，完整稿和最终决定仍由你写。

合理替代答案的待核方向：可朗读/非冒充合成声/字幕无声版或暂缓；需完整事实文稿、相应依据/成品核查与三渠道条件分支。

完整展开：`npx tsx scripts/prepare-ai000-release-readiness.ts --show-task AI000-C06-L03 review-lecture-release`
