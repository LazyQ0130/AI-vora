- generation/llm：编辑可含生成、分类文字不等于开放创作；常见LLM/DL联系的保留条件是否足够？
- product：界面/检索/模型分工和当前能力证据。
- takeaways：旧句“尚未制作”已登记RR-001，本轮只拟最小改法；不改变正文或r1。
