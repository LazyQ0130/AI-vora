## 核心概念、事实与争议点

- name-parameters：输入/形式/参数/预测作用和单位；没有宣称手设值为实际训练结果。
- compare-records：甲2/6/4差2/1/6合9，乙4/8/6差0/1/4合5；同输入不同目标无法全吻合。
- 两核心题：P8/7、Q4/5及总差打平；自选新非负参数须全部重算，不能逐行换参数。

这些是审查问题，不是已发现错误或人工审核结论。教师应亲自定位原文、重算数据/图示，指出误解机制、目标影响与阻断判断。

### compare-print-settings · 换一组参数，预测会怎样变化？

核心位置 `print-parameters-task`；目标 1、2；[完整题设/两级提示/全部5步解答与4项rubric](https://github.com/LazyQ0130/AI-vora/blob/fc30c72d5572bea05bafd9f9b5b55a54150d634b/src/content/lessons/ai000/models-and-parameters.ts#L84-L95)。

提示一（当前稿）：把每条的份数代入同一计算形式，分别放甲、乙的参数。先算乘法，再加基础值；与实际比较时，多估或少估都要算差多少。

提示二（当前稿）：P有3份，甲从2+2×3开始，乙从4+1×3开始。Q只有1份，也要各算一次，不能照抄P的优劣。

合理替代答案的待核方向：表或文字、其他补算均可，但四次甲乙代入和有限结论不可省；不以补算取代原比较。

完整展开：`npx tsx scripts/prepare-ai000-release-readiness.ts --show-task AI000-C04-L02 compare-print-settings`

### adjust-library-settings · 从历史记录出发，怎样改进预测？

核心位置 `adjust-parameters-task`；目标 1、3；[完整题设/两级提示/全部6步解答与4项rubric](https://github.com/LazyQ0130/AI-vora/blob/fc30c72d5572bea05bafd9f9b5b55a54150d634b/src/content/lessons/ai000/models-and-parameters.ts#L100-L112)。

提示一（当前稿）：先看当前预测是普遍偏低、偏高，还是不同记录方向不同。改参数会同时影响多条记录，不能只替一条量身换数。

提示二（当前稿）：当前对1册和2册的预计都少1分钟，可以先尝试只增加基础值。再检查4册那条：同样的变化是否也有帮助？

合理替代答案的待核方向：接受任何同一组非负、至少改善一条且三条均核算的新设置，不要求最优或必须有变差。

完整展开：`npx tsx scripts/prepare-ai000-release-readiness.ts --show-task AI000-C04-L02 adjust-library-settings`
