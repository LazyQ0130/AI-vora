## 学习目标与先修

1. 解释AI、ML、DL的包含关系，并用两个反例说明不能等同（核心题：draw-method-map）
2. 用多层表示的直觉说明深度学习为何属于机器学习及其与其他方法的差别（核心题：draw-method-map）
3. 根据新系统给出的方法证据归类，区别明确排除与仍然未知的信息（核心题：method-evidence）

先修：已读1.1与1.3，能说明输入/任务/输出，并区分知识推理与从数据学习的基本办法。无需数学或编程。

- 1.1 输入、任务与输出：`/learn/AI000/AI000-C01-L01#many-tasks`；回看系统拿到什么、交回什么，再把任务与本节的方法范围分开。
- 1.3 普通自动化和 AI 有什么区别？：`/learn/AI000/AI000-C01-L03`；回顾知识方法与数据学习，避免仅凭功能判断方法。
