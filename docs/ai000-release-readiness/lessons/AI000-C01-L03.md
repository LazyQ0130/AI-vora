## 学习目标与先修

1. 比较普通自动化、知识推理和数据学习在得到结果时的区别（核心题：identify-systems）
2. 根据系统已给出的方法证据判断是否涉及AI，信息不足时说明条件与追问（核心题：identify-systems、trace-method）
3. 沿着简单知识规则推出结论，并说明结论的范围（核心题：trace-method）

先修：能使用1.1的输入/任务/输出分析，并知道从例子学习形成模型；1.2已讨论任务结果的检查。

- 1.1 三要素与学习的直觉：`/learn/AI000/AI000-C01-L01`；本节不要求任何编程知识。
- 1.2 为结果找核查依据：`/learn/AI000/AI000-C01-L02#check-output`；回看怎样按任务选择对照，再用于本节的方法与结论核查。

## 核心概念、事实与争议点

- automation/knowledge：规则数量、普通自动化和专家系统推理的界限是否有足够方法证据？
- knowledge-trace：两条规则、中间结论和非唯一故障的图示逐项核对。
- evidence/practice：未知与明确排除是否分开，问题是否真正补任务/方法信息？

这些是审查问题，不是已发现错误或人工审核结论。教师应亲自定位原文、重算数据/图示，指出误解机制、目标影响与阻断判断。

### trace-method · 沿着水泵规则走两步

核心位置 `practice`；目标 2、3；[完整题设/两级提示/全部3步解答与3项rubric](https://github.com/LazyQ0130/AI-vora/blob/fc30c72d5572bea05bafd9f9b5b55a54150d634b/src/content/lessons/ai000/automation-and-ai.ts#L48-L52)。

提示一（当前稿）：先用第一条得到中间结论，再看第二条所需条件是否齐全。
