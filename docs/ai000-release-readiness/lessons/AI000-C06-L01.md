## 学习目标与先修

1. 用具体案例解释语言流畅与事实可靠的区别，说明生成回答与外部事实核查是不同环节，并分析不可靠说法可能来自哪些资料或使用问题（核心题：audit-submission-answer、write-venue-answer）
2. 把回答拆成可核查的事实主张，对照原始资料及适用条件区分有支持、与资料矛盾和暂时未知，分别检查来源存在性与引用有效性（核心题：audit-submission-answer、write-venue-answer）
3. 修正或独立撰写有依据、可回查且不过度承诺的回答，保留资料缺口，并为未知或冲突设计可执行的后续核查步骤（核心题：audit-submission-answer、write-venue-answer）

先修：已学过生成式AI与LLM、按资料组织回复，能读简单表格和回查来源编号。准备纸笔即可，无需编程、模型账户或真实联网答题。

- 1.2 对照资料核查输出：`/learn/AI000/AI000-C01-L02#check-output`；回看初步核对具体说法的办法。
- 2.2 LLM与当前上下文：`/learn/AI000/AI000-C02-L02#llm`；需要时补修语言模型怎样利用本次材料。
- 5.1 从资料到有出处的回复：`/learn/AI000/AI000-C05-L01#write-reply`；沿用查资料与组织语言分开检查的习惯。
- 5.1 资料缺口与补查路径：`/learn/AI000/AI000-C05-L01#keep-unknown`；回看没有说明的政策怎样保留待核。

- evidence-review：事实与引用两轴，票价免费不推出停车免费；R9仅题设清单不可用，不做全球不存在断言。
- submission-audit-task：S1一般/S2软件例外/S3仅改截止，3人事实对但错引，退费未知不判不退。
- venue-answer-task：11月20日周五、19:30–20:30覆盖、17/18/19完整自然日与资格/审批分开；题干与书写负担。

### audit-submission-answer · 交一份事实与引用分栏的审查记录

核心位置 `submission-audit-task`；目标 1、2、3；[完整题设/两级提示/全部9步解答与5项rubric](https://github.com/LazyQ0130/AI-vora/blob/fc30c72d5572bea05bafd9f9b5b55a54150d634b/src/content/lessons/ai000/unreliable-answers.ts#L107-L135)。

提示一（当前稿）：先把同一句里能分开成立的说法逐项列出，给每项保留原来的对象、日期和引用编号。暂不因为找到一个正确细节，就接受整段。

提示二（当前稿）：做两列清单：原文实际改动了哪一项、还有哪些事项未改。再任选一个主张，分别查它的事实依据和括号里的资料编号；把两次检查留在不同格中，其余主张也用同样办法走一遍。

合理替代答案的待核方向：可不同拆分/语序或分表，只要至少五条且覆盖全部关键说法、事实/引用分开并交完整修正版。

完整展开：`npx tsx scripts/prepare-ai000-release-readiness.ts --show-task AI000-C06-L01 audit-submission-answer`

### write-venue-answer · 交一份有引用、保留未知的场地答复

核心位置 `venue-answer-task`；目标 1、2、3；[完整题设/两级提示/全部9步解答与5项rubric](https://github.com/LazyQ0130/AI-vora/blob/fc30c72d5572bea05bafd9f9b5b55a54150d634b/src/content/lessons/ai000/unreliable-answers.ts#L141-L169)。

提示一（当前稿）：先把咨询里的资格、时段、物品费用和提交要求分成可单独回答的问题。为每项找原文，留空的格不要靠常识填满。

提示二（当前稿）：在日历上标提交日和活动日，只把两者之间完整经过的日期逐个圈出；再画所需时段与通知允许时段，比较端点。最后把拟答的每个确定句连回一条原文，连不上时记录缺什么证据。

合理替代答案的待核方向：可简洁分项或连贯答复、不同正式补查渠道；三日计算、范围、批准未知及投影未知不变，无需硬造矛盾。

完整展开：`npx tsx scripts/prepare-ai000-release-readiness.ts --show-task AI000-C06-L01 write-venue-answer`
