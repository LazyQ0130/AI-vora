## 核心概念、事实与争议点

- nlp-stages/cv-stages：阶段产物/继续/补修、数据检查从一开始；已有模型使用与训练、人工框与自动能力。
- catalog-task：植物三条/星空一条/无命中、同名作者区分、L04未知；至少三阶段及失败回补。
- image-choice-task/course-connections：P12错/3÷4=75%只是表内，允许缩小B优先；课程实际依赖与开放范围不排唯一长链。

这些是审查问题，不是已发现错误或人工审核结论。教师应亲自定位原文、重算数据/图示，指出误解机制、目标影响与阻断判断。
