## 完成的改动

- Hero：原创星球地平线与低角度山脊；live HTML 标题与 SVG 品牌组合；左侧渐进遮罩、分层景深、轻微鼠标视差。手机调整裁切与遮罩，保持文案对比度。
- 卡片：五类生成封面替代原图标封面；状态、编号、正文与先修信息仍是 HTML。统一边框、阴影、层级、箭头与悬停缩放。手机首页采用完整横向封面与纵向卡片；课程总览保留便于扫描的紧凑布局。
- 阅读：重整上下文导航、章节编号、课程缩略图、正文分区、概念/图示双列、公式、代码与练习层级；正文增至 14px，并保留长公式与代码的局部滚动。
- 定位：五个内容导航入口吸顶；顶部滚动进度线；左右目录同步高亮，左侧目录在需要时自行滚动；手机导航与内容入口保持可达。
- 性能：使用 memo 隔离静态内容块，滚动进度更新不反复执行 KaTeX、代码高亮或回归演示计算。没有新增后台、运行时代码执行、AI API、视频或认证。

## 本轮发现并修复的问题

1. 手机纵向卡片的 min-content 撑宽网格：增加 `minmax(0, 1fr)`、子项最小宽度约束，六档复查通过。
2. 百分比 IntersectionObserver rootMargin 受宽度影响，超宽屏目录高亮滞后：改为随滚动帧更新的固定像素阅读基准线。
3. 手机抽屉关闭时焦点恢复干扰锚点：先解除抽屉，再滚动与聚焦目标标题。Escape 关闭仍保留正常焦点恢复。
