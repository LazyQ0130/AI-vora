# Aivora 教学可视化标准 V1 草案

2026-10-27修订。适用于后续各课程的视觉内容选择与审查；仍为草案，不替换《课程内容编写与编辑规范V1.0》。沿用原文件名以保留历史链接；上一版“情境插画”建议及已发生的生成工作可在905aa46提交与历史报告追溯，不能将旧数量目标继续当作新课要求。

## 不设图片数量指标

教学图应当承担讲解工作。每篇可以没有图片、有一张精确图、有几张职责不同的图，或有必要的实例照片；不存在“每节一张”、13/13接入、固定图文比例、每几个H2加一图等验收指标。学生能更容易完成哪项观察、比较、判断或推理，是决定是否展示的依据。已经生成、风格统一、可能增添兴趣，不能单独成为保留理由。

先完成学习目标与知识讲解，找出具体理解困难，再判断是否需要视觉表达。图片生成不是默认生产步骤，不先定配额再倒推用途。没有必要的图就不补图，也不因移除场景画而删掉有效的概念图或数据。

## 三类视觉内容及默认处理

|类型|应承担的任务|选择与处理|
|---|---|---|
|知识可视化|呈现关系、数量、变化、流程、对比、层级及有依据的条件或因果联系|优先用可选择文字的HTML/CSS/SVG、数据表或程序图。数字、标签、箭头、包含关系与条件必须可核对。观察到关联不能画成已证明因果。|
|必要实例图片|展示文字难以充分传达、且与当前目标直接有关的外观差异或真实输入/结果|须让学生观察具体差异，例如同一物品遮挡前后、受控的输入与生成结果对照；说明对象、来源、条件与可得结论。静态拼在一起不能证明检索/编辑/生成过程。|
|重复情境的场景插画|仅展示人物看电脑、收发室登记、馆员看卡片、桌上摆资料、机器人站在走廊等环境|默认不进入教材正文。只有通过下列五问并确有无法由现有内容替代的教学信息，才讨论保留；不因成本投入强留。|

生成图片不应承担准确的中文、数据标签、公式、数值流程或包含关系。确需实例图时才选择合适素材或生成能力；保留来源与制作记录，不冒充真实实验、模型成绩或可靠性证据。美观、配色和风格是教学必要性通过后的次级质量条件。

## 每项视觉内容的五问准入

|问题|审稿记录必须具体到什么|不充分的回答|
|---|---|---|
|对应哪项正式目标？|写出目标号、可观察动作与相关练习；指出图帮助完成哪一步|“建立直觉”“增加兴趣”而无具体动作|
|哪些可见信息帮助理解？|指出图里的实际数据、标签、位置/形状差异、连接、顺序或变化及其含义|“有工作人员/书/屏幕，所以符合主题”|
|移除后失去什么独有信息？|明确仅靠当前文字或表格难以观察的差异；没有则记录没有|“页面会单调”或把情境重复称作独有知识|
|其他内容是否表达得更清楚？|比较现有section、表格或图；解释保留两者的不同职责|仅说各有优点，不指出内容增量|
|阅读空间值得吗？|说明学生此刻为何需要停下观察，以及位置、尺度是否合适|“已经生成”“图很好看”或固定数量要求|

缺少独有教学贡献时移除或不制作。若图片承载必要知识，先确保这项知识保留在恰当的正文/精确图中，再按实际核心变化判断版本，不能连知识一起删掉。五问结论属于编辑判断，需接受教师及目标学生检验，不由图片文件存在或截图好看来证明。

## 概念图的四项复核

1. **看图能回答具体问题。** 先写预期问题与可支持的答案。监督图应能区分照片输入、已知类别、新预测；参数图应能解释同一输入换参数后的变化；数据用途图应能追踪哪些记录何时影响选择。没有这些可见信息就不能以“包含相关物品”通过。
2. **不替代必要解释。** 正文说明概念、符号、单位、假设和读图次序；学生不必猜图。关键结论有文字支撑，图片失败或使用读屏工具时仍能学习。图注帮助读出关系，不放制作流程或宣传词。
3. **技术信息可核对。** 复算数值、公式和单位；核对箭头起止/方向、标签、阶段、包含范围与比较条件。比例、轴或面积有意义时准确绘制，没有数量意义时说明。优先由同一数据源生成图与表，再用独立预期检查，不能只核对两份同源输出。
4. **阅读节奏自然。** 放在学生正需要观察之处，图前有任务、图后有解释。两段文字足以讲清时不硬插大图；多图各有不同任务，避免同义堆叠。尺寸按内容选择，不用宣传横幅挤压讲解。

## 实施与技术验收

流程为：学习目标与讲解→具体困难→是否需要可视化→选择结构图/表/实例图→写看图问题及五问→核对来源/条件与数值→实际页面检查→教师审稿与学生试学。无图也可以通过，不设置生图工具调用或代表样图的必经指标；只有确实选择了新图像制作时，才做样图筛选及必要修正。

复用现有image Schema、LessonImage、Next/Image、HTML图组件与本地静态资源，不因一次删图重做阅读器或通用组件。必要实例图片实际编码、宽高、alt、图注、加载与原图入口均需校验；需要时提供手机构图，不机械双份。图片优化和视觉风格不能代替教学必要性审查。

检查1440/768/390/320等实际视口，正文无整页横向溢出；长表或公式可局部滚动，不能缩小全页文字。使用键盘与读屏语义检查标签和焦点，图不能只靠颜色区分关键角色。保证段落、图注和引用一致，不留“看下图”却无对应图。

## 版本、档案与交接

仅移除冗余场景块而保留核心正文、目标、习题、答案、rubric及锚点时，按既有规则保留contentVersion与进度，不据版面变短调整学习时间。核心考核若实变，应升版并保留旧记录，不能继承为新版完成。

历史图片与生成记录可作为归档素材保留，但清单必须区分“曾生成/接入”和“当前正文展示”。旧批量接入脚本应停用，不能让prepare或常规校验重新插图、覆盖旧证据。清理资源需检查历史链接，遵守工作区文件安全规则。

交接区分AI辅助审读、技术检查、专业教师/中文编辑审核和真实目标学生试学。不能仅由截图简洁推断理解提升；试学需记录学生能否依据图回答具体问题、误解、提示使用和实际耗时。本草案仍待这些证据验证。
