# Aivora 课程插画制作建议 V1（草案）

2026-10-27。此稿不替换课程编辑标准V1.0，待教师、编辑和真实学生验证。试行范围为AI000十三节；不据一次AI自查宣称已形成正式视觉规范。

## 两种视觉材料各做什么

精确的数字、公式、标签、箭头、技术集合、输入目标、参数、奖励与数据用途继续使用HTML/CSS/SVG或程序图。情境插画帮助看见人物、物品、动作和任务发生的地方，不承担精确计算和技术流程证明。两者互补；现有精确图和必要文字不删、不替换。即使图片失败，正文和核心任务仍完整。

## 开图前的四问

逐课记录：难想象什么；画面帮助看见什么；放在哪个section的哪段后；学生应更容易回答哪个问题。无法说明则重新设计或舍弃，不用装饰图片凑配额。完整提示词及四问放维护清单，不展示给学生。

## 视觉语言

采用现代教育编辑插画，柔和的二维/三维混合质感，真实自然的物品和比例，少量细节、一个清楚动作。以海军蓝/靛蓝、青色、米白和少量暖琥珀协调深色页面；允许明亮图书馆与纸面改善节奏。避免摄影式伪实录、幼稚贴纸、发光电路/大脑/全息屏装饰、十三张同构人物看电脑。常规3:2或16:9，正文内正常幅宽，主体在手机约300px宽时仍可辨识，不作宣传横幅。

生成提示统一含风格约束，但每张另写场景、动作、视角、信息边界。图中不生成中文、英文、数字、公式、标签、准确UI或数据表。无字屏幕只能用简洁卡片等形状暗示工具，不能伪造界面事实。需要的标记由准确HTML图注或已有技术图说明。

## 生产与筛选

先留实际基线和十三课计划。先做邮件、送物、数据保留、新包裹四张代表图，逐张看生成原图及真实阅读器桌面/手机；确认配色、物体、教学作用和与精确图的间隔，再继续其余场景。用当前可用的内置image_gen工具逐张生成，不自动退到API或不明网图。工具失败按真实状态交接，不造占位图冒充成果。

检查手部与物体、透视、包裹/文件袋区别、岔口通行、资料是否被提前使用，核对alt/图注与画面。不合格时单项修正或重生成；旧候选留生成工具目录供追查，不全部放进生产目录。生成图不是实际实验或模型成绩的证据，不能用风格掩盖概念误导。

## 接入与文件

最终选中素材放public/images/lessons/ai000，明确课时/主题命名。保留生成原文件路径和完整提示词于清单；网页仅提交优化WebP，准确登记实际宽高和编码，避免把扩展名改作编码。等比例缩放/格式压缩只做交付优化，不用它悄悄修画面错误。需要修画面时回生成工具。根据实际构图判断是否另做手机图，不机械复制双份。

复用现有image块、LessonImage和Next/Image：本地src、alt、caption、width/height，现有sizes与浏览器懒加载。不开CDN、不加运行时生图/API、不重做查看原图或阅读器。目标：长边约1200px、单图尽量低于250KB（超出需说明），读者实际获取由Next/Image按尺寸优化；不通过牺牲清晰度硬凑体积。保留固有比例，实测加载前后区域尺寸和手机溢出。

## 图注、兼容和验收

alt描述重要物品与动作，不写8K/精美/原创口号；图注联系当前问题，不反复写生成声明或维护记录。关键知识仍有正文，必要来源记录在清单。旧课仅增加经登记的图片块及自然图注，版本按原规则保留；不改目标、原段落、练习、答案、rubric或section/练习ID，旧进度不删不迁移。

逐图检查路径、真实编码/宽高、文件大小、非空白、无水印文字、角色一致性及来源。连续看十三课并记录每课图片加载、视口尺寸、原图入口；代表课保留桌面/手机截图。四宽度覆盖1440/768/390/320；模拟不等于实体设备。测试、AI视觉自查、教师内容审查和真实试学分别留证；图片不能替代学习证据。
