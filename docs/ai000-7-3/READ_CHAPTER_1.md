## practice / describe-task

同学说：“录音转写软件用了AI，所以它应该知道老师说的结论对不对。”已知软件使用学习得到的模型，只把课堂录音转成文字。请用自己的话解释这里AI的作用，写出输入、任务和输出。再说明转写正确与结论正确为什么是两个问题，给出一个分别检查它们的办法。

提示：先想软件接收的是声音还是知识结论，交回的东西是什么。 / 把“声音里的原话”和“原话谈到的事情”写成两行。为各行想一份能与它直接对照的材料，再检查两行是否需要同一种依据。

自查：用自己的话联系识别任务解释AI作用。；准确指出录音输入、识别任务、文字输出。；区分两项工作，并各给出相关的检查依据。

## practice / design-task

学校有一批失物照片，准备请工作人员核对后整理目录。请设计一项范围清楚的AI辅助任务：写出输入中需要什么、希望系统做什么、输出是什么；给出两个可能的输入与输出例子；说明工作人员随后要做的一件事。不要直接把任务写成‘找回所有失物’，也无需设计算法。

提示：先选一种工作人员能核对的工作，例如在几个类别中归类，或辨认照片上的文字。 / 先选一个照片中可观察、工作人员也能核实的特征或工作，再为两个不同输入写出对应的输出形式。检查你的输出有没有暗中回答照片本身不能证明的事情。

自查：需求被限定为一项明确工作，输入确实能支持它。；两个例子与所选任务的输出形式一致。；解释AI的辅助作用，并把人工核对等后续动作说清。

## practice / compare-service-tasks

为甲至丁各写一行：实际输入、要做的任务及名称、期望输出、一个能判断是否达到要求的核查条件。说明四种输出为什么不能互相替代。再解释：丙排在前面的书能否保证读者一定喜欢？甲若准确记下某句话，能否证明那句话内容真实？分别给出理由。无需设计软件或算法。

提示：先写工作人员最后想拿到什么，再回看题目提供了哪些材料；让核查条件对应这份交付物。 / 选一项先补完‘拿到这些材料后，交回……，再与……比较’，其余三项也各写一次。若一个输出还被拿来作别的保证，检查那项保证是否属于原来的任务。

自查：四项均有与需求匹配的输入、任务和实际输出，四种用途有清楚区别。；每项有可执行且对应交付的核查条件，不只列任务名称。；解释推荐基于已有偏好线索仍不保证此刻喜欢，并给相关核查。；区分原话被准确记下与原话内容真实；接受任务名称的合理联系，不抹去用途差异。

## practice / check-library

图书馆系统把记录分为“需要提醒归还”和“无需提醒”。教学记录为：A已逾期→系统需要提醒；B已按时归还→系统需要提醒；C仍在借期内→系统无需提醒；D已逾期→系统无需提醒。以题设记录为可靠对照，逐项判断对错，指出误提醒和漏提醒，说明各一个后果。再写一个在发送提醒前可执行的核对步骤。无需计算准确率。

提示：分开看记录本来需要什么和系统判了什么。 / 给每行补一列“按已知记录应提醒吗”，再和系统列逐格比较。找到两列不一致的行后，分别说明系统多做了什么或少做了什么；核查要回到哪份原始记录？

自查：四项结果与题设对应。；分清B误提醒、D漏提醒，并联系后果。；核对步骤有独立可靠依据和错误后的动作。

## practice / product-review

小店准备给商品照片分成杯子、碗、盘子，分类器从已分类照片中学习。新照片可能是把手被遮住的杯子、俯拍浅碗，也会出现未见过的器具。另一项请求是按商品记录写一段介绍。比较这两项任务的输入和输出；为分类举一个可能做对的情况和两个具体错误原因；设计初步核查方案，写清依据、要覆盖的照片、比较项目和错了或不确定时的处理。最后说明介绍文字应另核查什么。

提示：先分别写照片→类别、商品记录→介绍，再分析条件变化。 / 先选一张具有题设条件变化的新照片，写出它和可靠对照应怎样配对；再给核查表留出预期类别、系统输出、后续处理三列。介绍中的每个可核实说法，也要能指向某份记录。

自查：比较两项任务时输入、输出和用途清楚。；至少一个可能正确情况及两个有原因的错误机制。；方案有可靠对照、不同条件、新例子和逐项记录。；错误/不确定后有实际处理动作，文字说法另查来源。

## practice / identify-systems

分析四个教学情境：甲仅按设定时间复制文件；乙把园艺人员输入的植物知识和多条现象联系起来，按推理规则提出养护排查建议，没有学习模块；丙从已分类的包装照片中学得模型，给新照片判断包装类别；丁只说“智能整理资料”，没有更多说明。各写任务与输出，说明按题设无需AI、涉及AI或信息不足的依据；对丁写一个能补充任务信息的问题和一个能补充方法信息的问题。最后解释为何不能只用是否自动运行来区分这四项。

提示：先找题干里明确说的步骤、知识推理或从数据学习，不以名称判断。 / 为每个情境圈出动作怎样执行、判断关系怎样形成的证据句，再检查你的结论是否用了题干没有给的条件。对丁，把任务证据和方法证据留在不同空格里。

自查：四项都说明任务/输出，丁承认这部分也不足。；判断依据来自题设的方法信息。；丁的两个追问分别补任务与方法。；解释自动化与AI方法可同时出现，条件性结论明确。

## practice / trace-method

教学诊断系统只有两条规则：供电指示灯亮→设备已通电；设备已通电且没有出水→优先检查进水条件或泵体。现象是指示灯亮、没有出水。写出每一步可推出什么、用了哪条规则；能否据此断定电机一定转动或泵体一定坏了？若产品后来只告诉你“有很多规则”，还可以直接确认它用了知识推理吗？说明理由并提出追问。

提示：先用第一条得到中间结论，再看第二条所需条件是否齐全。 / 把第一步推出的词写到第二条规则的条件旁，检查还要哪一条现象才能继续。对题目问的两个确定结论，分别找一条能推出它的规则；找不到时想想结论该怎样表达。

自查：两步各有对应条件、规则与结论。；没有从通电推断必定转动，也没将方向当确诊。；能区分完整机制描述和只知规则数量，并提出有区分力的问题。
