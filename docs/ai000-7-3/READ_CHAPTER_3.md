## practice / prepare-examples

图书角想根据书的封面照片，给新书提出类别建议，工作人员随后核对。请自定两到三个有用的类别，写清任务、输入和输出。构造三条不同的学习样本，每条写照片中可见的信息、已确认类别，以及类别怎样核实；解释哪部分是输入、哪部分是标签，为什么这属于监督学习。再构造一条新照片，说明模型预测什么、预测前是否必须先知道正确类别，以及工作人员怎样核对。最后指出只凭封面可能判断不准的一种情况。所有例子可为教学假设，不需要上传真实照片。

提示：先选工作人员能够核实的类别，再为每个例子把照片信息与已确认类别配成一对。想想核对答案是否要另查资料。 / 先完成你自拟的一条样本，检查照片中可见的信息与确认类别用的资料是否被混写。然后把它改成一条还没有核实结果的新记录：哪些内容仍能交给模型，哪些要等工作人员检查？

自查：任务、类别和输出清楚，三条样本各有输入/标签配对及可信的确认方式。；能用已知目标在学习中的作用解释监督学习，未把标签当预测。；新输入的预测、未知真实类别和后续核实分清；解释预测前无需先给答案。；给出一个有理由的输入局限，允许有条件的不同方案。

## practice / missing-targets

分析四个独立情况：甲有一批工具照片，每张都按同一标准确认了扳手/螺丝刀/其他类别；乙有很多工具照片，没有类别记录；丙有历史订单的发单距离、发单时间段和逐单记录的实际配送分钟数；丁只说某产品“智能预测，非常准确”，没有输入、目标或训练说明。逐项写已给输入与已知目标、可开展或拟定的监督学习任务、仍需补充/检查的资料。对丙再说新订单预测时能拿到什么、结果何时可核实；对丁写两个能帮助判断的追问。不要仅凭照片数量或产品名称判断。

提示：把“有输入”“有明确目标”“两者能否对应”分别检查。缺少目标时可以准备目标，不用先猜另一种学习算法。 / 先逐项写出一条记录的形式，给尚缺的部分留空。再把预测时刻与目标取得时刻画在一条时间线上：你拟定的输入能在预测之前得到吗？补数据方案应填哪一个空格？

自查：四项各分开写输入与目标，缺项如实保留。；甲不保证效果，乙有明确可行的补标签/核实方案。；丙区分数值目标、新单当时输入和送达后的对照。；丁保留方法未知并提出两个能补证据的追问，理由来自给定信息。

## practice / propose-groups

以下全部为同一个月的虚构活动参与次数：P：运动5次、艺术1次；Q：运动3次、艺术2次；R：运动1次、艺术4次；S：运动0次、艺术2次；T：运动4次、艺术4次；U：运动1次、艺术0次。没有提前给参加者分好人群。请写出输入信息，自选一种明确的比较依据，提出候选分组，并逐组用数字说明理由；选一条不容易解释的记录，说明如何处理。解释为什么可以用无监督聚类的思路分析。再换一种依据，重新分析哪些记录接近、哪些关系改变；若自定分档，写明界限。找出总次数相同、两类构成却不同的一对，说明只看总数会忽略什么。最后单独写U的记录事实，以及不能据此确认的长期兴趣或能力；再列一项其他未知，为所列未知提出相关核查动作。无需公式或算法。

提示：先选你想比较什么，再让每条记录按同一依据接受检查。把两列相加有助于发现另一种关系；组数无需照搬正文。 / 可以比较哪类更多，再核算六个总数。找一对总量相同但构成不同的记录。T的均衡与参与量分别说明什么？U只有一次记录，区分已经观察到的次数与仍需核查的兴趣解释。

自查：输入与比较依据明确，逐组用新数字支持，并处理一条难解释的记录；分法可不同。；说明探索分组没有预给人群答案；手工方案不冒称算法输出。；更换依据后准确核算关系，自定分档写明界限；找出Q/R同总量但构成不同，解释忽略的信息。；U事实为1次运动、0次艺术，保留长期兴趣/能力未知；另列一项未知，核查动作与未知对应。

## practice / identify-learning-signals

甲准备器材照片及工作人员确认的器材类别，计划利用这些配对学习，预测新照片的类别。乙只有行为记录中的活动类型（运动/艺术）及参与次数，没有人群组别；计划不使用预先确认的人群答案，让程序从行为相似处寻找分组。丙有历史订单信息及逐单记录的实际配送分钟数，计划据此学习并预测新订单时长。丁只宣传“智能发现规律”，没有数据或方法说明。逐项写任务、输入、是否给了当前任务的已知目标标签、可以判断的学习方式及成立条件、还缺什么资料。若乙得到“组1”，能否据编号确认固定兴趣或能力？解释并给一个实际核查步骤。对丁写出有区分力的追问。

提示：看已知目标是否被用于当前学习任务，不按有没有“类别”两个字或是否有人手填判断。计划采用的学习安排与产品已实现的算法也要分开。 / 为每项另写“程序要学会交回什么”，再从给定记录里找有无对应答案。某列描述了活动，不等于它已经回答你刚写的学习问题；要逐项说明理由。

## practice / design-self-task

自拟一条包含时间、地点或动作的完整活动通知，也可用教学句“周一午后，志愿者在体育馆清点器材。”。选择一个词或片段遮住，分别写完整原文、遮盖规则、模型实际接收的输入、能从原文取得的目标。再给出一种可能的模型预测，说明怎样与目标比较，以及为什么这可以作为自监督任务。最后举一个原始数据残缺或遮盖方式不合理的情况，说明会妨碍哪一步、怎样处理。请使用与正文不同的句子，不要求预测一定相同，也无需写代码。

提示：先选一份你确实保留完整内容的短文本，圈出要遮的片段。分别记录剩下给模型的内容，以及原来圈出的内容。 / 目标要从原文圈出的位置取得，不从模型预测取得。可以尝试遮动作或时间；若原句已缺掉那一部分，就无法按同一办法还原出对照。

自查：完整原文与遮盖规则清楚，输入确实隐藏所选片段，目标能逐字回查原文。；给出一种预测并准确比较，与目标相同或不同都可，不能反写目标。；用数据自身取得目标解释自监督，而非只说没有人工标注。；指出一个具体的残缺/构造问题及受影响步骤和可行处理。

## practice / compare-learning-tasks

甲用已经核实类别的植物照片配对学习，预测新照片类别。乙没有预定顾客群标签，按商品浏览记录的相似处学习分组。丙保留一批完整文本，自动隐藏部分内容，让模型预测隐藏片段，并以原始内容作目标。丁只宣传“利用海量数据自主学习”，没有其他说明。逐项写学习时可用的数据、有无明确目标及目标来源、对应的学习安排、判断理由和仍不清楚的信息。对丙再用原句“闭馆后，工作人员把桌椅摆整齐。”遮住动作，分别写原文、学习输入、目标和一种可能预测。为丁提出有效追问，并解释为什么不能仅用“乙丙都没有人工写好的组别”将它们认成同一个具体任务。最后说明为何也不应把三种名称画成永远不相交的圈。

提示：先追踪目标来源：核实类别、没有预定群标签、从完整文本取出的片段。只看“自主”或谁填答案都不够。 / 在丙的新句中圈出你选择的动作片段，先只写处理后的输入，检查剩余文字是否仍露出了答案。再分别填写目标和可能预测，追踪它们各自从哪里来。

## watering-task / trace-watering

用本题上方的规则和两条记录完成分析。先指出智能体与环境，把开始时的观察、可选动作及第一步后的新情况分开写，再追踪后面的水量与任务变化。分别计算两段累计奖励，解释第一步得分较高的一段为什么整体未必更好。最后说明奖励为什么没有直接给出每步正确动作，并写出至少一项这些记录无法确定的信息。可用逐步表格或连贯文字，不需公式或代码。

提示：先找谁在选动作，谁提供水量变化和分数。比较两条记录要一直算到两块地都完成，0分的动作也保留在过程里。 / “补满”是变成2单位，并非额外加2。分别列四步与三步奖励再相加；首次完成一块地的加分每次任务只有一次。

自查：分清智能体/环境、当前观察/动作，并准确追踪水量与两块地的完成状态。；计算包含全部四步和三步，得到6与11；说明0分补水怎样改变后续条件。；用奖励没有提供逐步正确动作解释与标签的差别，不只背术语。；列一项相关未知及证据缺口；替代过程需遵守同一规则，不宣称训练或最优证明。

## feedback-task / assess-feedback

先逐项写实际任务、学习所需信息、目标或反馈从哪里来，说明有没有给出连续行动影响环境的证据，以及可判断的学习安排。再为丙列当前观察、可选行动，并设计一项完成任务的奖励和一项等待代价，解释怎样取得记录、还需检查什么。最后为丁提出有区分力的追问，并比较丙的奖励与3.1已确认类别、3.3原文目标的作用。允许有条件的答案，但每项判断都要引用题设。

提示：不能按照片、设备或AI几个词分类。找出学习时实际用什么对照，尤其检查选择会不会影响接下来的情况。 / 丙能观察队列、机器占用，行动会改变后续等待；计分要兼顾完成和等待。丁只说评分，仍不清楚是否有行动反馈；甲的类别与自监督的原文片段，怎样作为对应目标？

自查：甲乙由目标来源判断，丙由行动影响后续和反馈学习判断，丁明确保留未知。；丙当前信息、可用行动、环境后果分清，奖励/代价有记录来源、约束与核查。；对丁的追问能补决策和反馈证据，不能只问是不是AI。；比较奖励与已有目标/数据构造目标的用途；允许组合与有条件方案，不声称适合就必然学好。
