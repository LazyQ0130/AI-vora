## practice / draw-method-map

不用照着教材描图，用三个框、缩进树或你自己的布局表示 AI、ML、DL 的包含关系。在 AI 内但 ML 外、ML 内但 DL 外、DL 内三个位置，各放一个有方法说明的例子；可以改编学过的例子，也可以自拟。为每个位置写一句理由，再向一位同学解释“为什么 AI 不等于机器学习”“为什么机器学习不等于深度学习”。只写产品名称不够，例如“识别软件”还需要补充它用的办法。 再为最内层补充解释：它为何仍属于机器学习？它学习多层表示与普通决策树的主要差别是什么？

提示：先想从最里面出发能否同时写上外面的名称，再检查外面有没有其他做法。例子的位置由实现方法决定。 / 先给一个自选例子写清判断关系的来源，再在图上试放位置：要进入内层，还需哪些方法条件？用同样办法检查另外两个区域，最后补全多层表示的解释。

自查：关系准确：DL 整体包含于 ML，ML 整体包含于 AI；没有把三个名称当作互斥选项。；三个区域各有一个例子，每例都写明足以支持归类的方法信息。；分别用 AI 中的非 ML 方法、ML 中的非 DL 方法解释两处不等同。；能用自己的话解释图，例子的成立条件清楚；不要求与参考解的场景或措辞相同。；用数据学习与多层表示解释DL的方法特点，没有把它理解成更像人或必定更准。

## practice / method-evidence

四个教学系统：甲只用人工设备知识与推理规则，没有学习模块；乙从花朵测量记录学出普通决策树，不使用神经网络；丙用从录音数据训练出的深度神经网络判断声音类别；丁只说明“使用机器学习”，没有说明模型结构。逐项写AI/ML/DL中能确定的范围、任务或尚未说明的任务，以及判断依据。明确哪些类别被题设排除，哪些只是未知。对丁补一个有用的追问。最后解释为什么不能只凭输入是图片、声音还是数字来决定是否使用DL。

提示：先找知识推理、从数据学习、深度网络三种方法证据。 / 先对每个范围标“有支持、已排除、尚无说明”，并在旁边圈原句证据。若某一栏未知，追问应能补那一栏的方法条件，而不是重复它的输入形式。

自查：甲乙丙的范围与排除均有方法依据。；丁保留DL与任务缺口，并提出追问。；解释输入形式不能代替实现信息。

## practice / classify-new-systems

甲从素材库返回一张已有节日海报；乙只把一张海报缩成指定尺寸；丙明确用从数据训练的深度神经网络，按文字要求产生新海报图像；丁明确使用LLM，把留言分成咨询/建议/其他；戊只宣称“智能创作”，没有输入输出或实现说明。逐项写任务、输出、能确定的方法范围及仍未知的信息。比较丙和丁的方法与任务。若戊补充“能按材料写摘要”，现在多知道了什么，能否确定它一定用了LLM？

提示：用题设处理过程判断任务，用明确的方法说明判断AI/ML/DL。两条依据不要混在一起。 / 把每项输出的来源写在旁边：来自现有内容的哪种处理，还是本次按要求组织？再单列题干明确给的方法，检查每个技术名称有没有对应证据。

自查：四类处理依据实际过程区分。；方法结论对应给定证据，未知项保留并能追问。；比较丙/丁及戊追加信息时不由任务唯一反推模型。

## practice / product-model-map

一个服务的说明明确写：先检索已核实的展览资料，再用基于深度学习的LLM组织回答；界面负责收问题和显示文字。请画出或用缩进写出产品、模型、任务的关系，解释生成式AI、LLM与DL怎样同时适用于其中部分步骤。为同一份资料分别拟一个类别判断请求和一个摘要请求，说明各自预期输出与核查依据。最后写两项仍不能仅凭该说明确定的信息。

提示：把界面、检索和LLM作为产品的不同部分，不要把三个名称全套成一个圈。 / 先为图中的每个部分写一个实际动作，再连材料怎样传递。两种请求分别列“必须交回什么”与“拿什么核对”，未知项从说明中未交代、但会影响这一步的内容里找。

自查：分工图清楚区分产品、模型、任务，说明DL归属。；准确联系LLM与生成能力，没把二者或整个产品等同。；两种请求有不同任务、预期输出与核查办法。；至少两项未知有具体含义，不编造能力和数据。
