## 2.1 用变量保留并更新程序里的值

主要问题：把一份任务文字交给名字后，后续读取为什么会变？先修见上表。首次内容仅将1.5的最小经验推广到普通脚本：变量名在当前执行过程绑定一个值，读取取得此刻绑定；执行赋值可重新绑定。暂不讲对象可变性、引用别名、作用域、静态类型或存储地址。

目标草案：①写出赋值与读取，区分名称和引号内文本；②预测同一名称重新赋值前后输出，修改并真实重跑；③依据执行顺序定位一次未定义名称的读取，修复后核对。

以下主例只用第一章已有字符串、print与最小赋值，在新.py中运行。先解释语句角色，再让学生预测；不能直接贴代码后要求猜变量定义。

<!-- example: c2-1-main -->
```python
task_name = "Pack notebooks"
print(task_name)
task_name = "Check labels"
print(task_name)
```

独立预期：两行Pack notebooks、Check labels。后一次赋值改变后续读取，不改写先前已显示的行；脚本每次从头执行，不依赖上次Notebook内核。核心新题与完整简报见后文。最终项目积累：把运行标签/中间值用有意义名称保存，未来才读取文件数据。

编辑估时：阅读10–15、预测/练习5–8、代码10–15分钟，共25–38；路径/编辑器故障另计。真实理解“当前值”及脚本重跑差别尚待试学。

## 2.2 分清文字、整数、小数和真假值

主要问题：输出都像3，怎样确认值的类型？进入时只需2.1，不要求输入/算术/转换。先对照`3`与`"3"`、`1.5`、`True`的意义与写法，再解释类型是值所属的种类，本节只认识str/int/float/bool。True/False大小写固定，`"False"`仍是字符串；float用于近似数值，不称任意十进制小数都能精确存储。

目标草案：①为文字标记、整件数、测量值、真假标记选择合适字面量并说明理由；②亲自运行type观察，区分相同显示与不同类型；③修改一个值后重新核对，说明名称本身不固定为某种类型。

`type()`在本节首次解释为查看值类型的内置工具；`print(type(...))`先算内层再显示结果。输出中的`<class 'int'>`等本节只读作类型标识，不要求理解class定义。先教这两步再使用以下完整主例，不依赖第一章sys诊断语法。

<!-- example: c2-2-main -->
```python
item_count = 3
count_text = "3"
item_mass = 1.5
is_ready = True
print(item_count)
print(count_text)
print(item_mass)
print(is_ready)
print(type(item_count))
print(type(count_text))
print(type(item_mass))
print(type(is_ready))
```

独立预期：前四行3、3、1.5、True；后四行依次int、str、float、bool的类型标识。独立代码证据：自选新物品文字、整数数量、测量数值、真假标记，先分类再运行；把一个整数值改为带引号的文字，比较前后类型与显示，交源码和短对照。rubric应核对字面量/实际类型/理由，不用长定义答卷代替操作。暂不教bool的数值子类关系、真假值转换、列表/类/类型标注。

项目积累：日后分清文本字段和数值字段。阅读12–18、练习6–10、代码12–18，共30–46分钟编辑估计；type嵌套观察的负担需教师复核。

## 2.3 用表达式算出一个结果

主要问题：多项数量怎样写成可检验的计算式？先修2.1–2.2。首次讲`+ - * /`、表达式先求值再赋给名称、乘除先于加减、括号改变分组、同级四则按从左到右求值。用具体数先手算，不把优先级表作为开头。除法即便整除也产生float；零作除数的现象可识别，核心输入限定非零，无需异常处理。

目标草案：①把新数量关系写成四则表达式；②先预测含乘法/加法与括号的不同结果，再执行解释；③修改一个已知数值重跑，并核对数值及单位。

<!-- example: c2-3-main -->
```python
box_count = 4
per_box = 3
spare = 4
total = box_count * per_box + spare
print(total)
print((box_count + spare) * per_box)
print(total / box_count)
```

独立预期16、24、4.0；两种算式代表不同的分组，不能只改括号迎合输出。独立代码方向：给未见的盒数/每盒数/散件，写总数及取走若干后的剩余数（先解释减法），预测并改一项验证；另用同一数据构造不同括号结果，说明关系是否仍符合题意。只用数字和变量；不提前input、容器、列表求和或函数。`// % **`可在正式编辑时作为明确可跳过拓展或后续按需桥接，本蓝图后续核心均不依赖它们。

项目积累：数量统计与单位意识，不读CSV。阅读12–18、练习6–10、代码15–22，共33–50分钟编辑估计；手算能力差异和单位解释待试学。

## 2.4 让比较表达式给出真假结果

主要问题：相等边界是否满足要求？先修2.2的bool和2.3的数值表达式。先比较具体数量，再逐步引入`< <= > >= == !=`；`=`执行赋值，`==`比较值，不将数学等号口语混用。先只做单一数值比较，不引入if或用布尔值驱动控制流程。

目标草案：①写数值比较并预测True/False；②区分赋值与相等比较；③手动把数量改为低于/等于/高于边界三种值，实际核对并解释`<=`与`<`差别。

<!-- example: c2-4-main -->
```python
count = 5
limit = 6
within_limit = count <= limit
print(within_limit)
print(count == limit)
print(count != limit)
```

独立预期True、False、True。独立代码方向：换一个容量情境与新上限，写三个单比较式；修改数字后逐次运行，不要求循环批量测试。rubric核对等于边界的实际结果与原因，不能仅认选项。暂不讲if、and/or/not、链式比较、字符串排序或浮点近似的相等性算法；例子用整数避免隐含数值误差问题。

项目积累：提供下一章可用于分支的条件表达式。阅读10–15、练习6–10、代码12–18，共28–43分钟编辑估计；六个符号的逐步节奏待教师判断。

## 2.5 取得用户输入，再转成需要的数值

主要问题：键盘输入看起来是数字，为什么还要转换？先修2.1–2.3，2.4按顺序已读但不是理解input的必要条件。首次先讲input的提示、等待、返回字符串，用纯文字输入/输出观察；随后出现数值计算需求才介绍int，再以小数测量需求引入float。先拆成输入文本→转换→计算三行，不在初次使用时嵌套成`int(input(...))`。

目标草案：①写出接收并显示文字的真实交互脚本；②将规定格式的整数或小数字符串明确转换并计算；③用两组合法输入检验结果，能根据实际ValueError指出不符合当前转换条件的输入，不要求写捕获代码。

以下为完成首次讲解后的整数主例；如要对比字符串`+`得到拼接，须先就地解释拼接含义和现象，不能假定学生已学过字符串运算。

<!-- example: c2-5-main -->
```python
label = input("Label: ")
count_text = input("Count: ")
count = int(count_text)
print(label)
print(count * 3)
```

输入Box A、4，程序结果为Box A、12。提示文字、用户键盘回显和print结果分开标注。整数转换先限定如`4`这样的十进制整数字符串；输入`4.5`或`four`时可能是ValueError，不教用eval或先转float再截断来“修好”。小数例在讲清float用途后使用：

<!-- example: c2-5-float -->
```python
mass_text = input("Mass kg: ")
mass = float(mass_text)
print(mass * 2)
```

输入1.5，预期3.0。独立代码方向：自己设计新标签和两组合法数值的“每份用量”脚本，保留实际输入/输出与类型解释；在受控副本中观察一次错误格式，指出需改输入条件而不是重装Python。保留技术支持/输入帮助记录，不让学生写长方案替代交互。无try/except、循环重试、输入校验框架、bool(input())、复杂字符串方法或文件解析。

项目积累：命令行取得运行参数；尚非健壮CLI。阅读12–18、练习8–12、代码18–28，共38–58分钟编辑估计；安装不重复，交互与错误观察负担待试学。

## 2.6 把输入和计算整理成清楚的输出

主要问题：怎样让别人知道每个结果是什么、单位是什么？先修2.1–2.5。首次只教f-string的f前缀、成对引号/花括号与插入已算出的名称；先解释后运行，不用格式迷你语言、方法调用、类或高级嵌套表达式。普通print仍是合法选择，不把某一种排版当唯一能力证据。

目标草案：①将已算好的名称插入带含义/单位的文字；②独立组合输入、明确转换、运算和比较为短脚本；③用两组新输入核对程序结果和边界判断，并解释数据流。

<!-- example: c2-6-main -->
```python
item_name = input("Item: ")
count_text = input("Count: ")
mass_text = input("Mass kg: ")
count = int(count_text)
mass = float(mass_text)
total_mass = count * mass
within_limit = total_mass <= 10
print(f"Item: {item_name}")
print(f"Count: {count}")
print(f"Total kg: {total_mass}")
print(f"Within 10 kg: {within_limit}")
```

输入Parcel、4、1.5，预期物品Parcel、数量4、总质量6.0 kg、Within 10 kg为True。程序中的比较使用已教内容，仍没有if。独立代码方向：在不同情境（如材料件数与单件长度）自行写输入/计算/带单位输出，手动试两组合法输入，其中一组恰在边界；提交短源码、输入/实际输出及一句原因解释。rubric核对数值、类型、单位、边界与真实执行，不要求长篇项目报告。`.2f`等格式指定留可选，不作为基础达标；不要求容器、CSV、Pandas、文件读写、函数或异常处理。

项目积累：可复跑的交互式摘要，为第三章加入条件选择、第四章处理多项数据准备。阅读12–18、练习8–12、代码22–32，共42–62分钟编辑估计。

提示1方向：本次从第一行开始，出错时这个名称已经获得值了吗？提示2方向：对照提供值与使用值的位置，保留同一主题和名称，自己安排执行顺序并实跑。
