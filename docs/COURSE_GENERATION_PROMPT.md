# 可复制的单课生成与精修提示词

每次填入一节目标后使用；精修时把“生成”改成“精修”，指定需要处理的证据。简报正文只有 [编辑规范第 12 节](COURSE_EDITORIAL_STANDARD_V1.md#editorial-brief) 一份标准模板，复制并填写到本次审查记录，不必复制整份规范。

```text
请在 Aivora 当前 main 的最新源码上，为下面这一节课生成或精修图文教材。

本次任务：<生成 / 有范围的精修>
courseId：<真实课程 ID>
chapterId：<真实章节 ID>
lessonId：<已有稳定 ID 或经蓝图核对的新 ID>
节级蓝图与范围：<实际路径及本节标题；不默认生成整门课>
已有问题证据（精修必填）：<源文件、section.id、原句/题目、具体疑问>
本轮证据目录：docs/<唯一目录名>

先完整阅读并遵守：
1. AGENTS.md，以及本次基线和工作区已有改动。
2. curriculum/ 的事实、现行节级蓝图、当前课及必要前后节。
3. docs/COURSE_EDITORIAL_STANDARD_V1.md：教学、中文、事实来源、习题与审核。
4. docs/COURSE_AUTHORING.md：模型、组件、资源、路由、进度及技术验收。
5. docs/COURSE_PRODUCTION_WORKFLOW.md，以及适用于当前稿件的最新审查。

第一轮先交付并留存课前编辑简报和事实来源，再生成该课：
- 复制编辑规范第 12 节模板并填写。读者第一次接触什么，已会什么，
  补修链接是否真的可读，本课要独立解决的核心问题是什么？
- 确定 2–4 个可观察目标，列出目标—正文支点—核心 exerciseIds—
  学生需产生的过程/解释—rubric 对照。目标编号从 1 起，与 lessonSchema 一致。
- 先求解主例与习题，写清数值、单位、方向/形状约定、预期输出和图形输入。
  先修不够或事实未确认时，说明缺口，继续做不依赖它的工作，不假装已核验。
- 登记来源 URL/仓库提交、版本和访问日期、具体核对点、许可与复用方式。
  优先官方资料、原论文和教材；AI 的回答不是独立事实来源。
- 根据目标决定核心、advanced、verification；数学核心不强制 Python。
  不把新先修塞入可选区后拿来考基础达标。
- 完成以上计划后，再写一篇自然连贯的单课。先具体例子，再解释新术语/符号，
  保留必要推导、边界与反例。H1/H2/H3 不带多级编号；课程目录保留课号。
- 采用现有 lessonSchema、assessmentMap、内容组件、资源模块与发布清单。
  不另造内容系统。代码说明运行环境/位置/预期；适合时安排先预测再运行。
  每道题保留两级提示、分步答案、错法说明与自查依据。
- 精修只改有证据的问题，保留正确数学含义和完整学习过程；记录不改的理由。
  不以字数、段落数、H2 数、关键词黑名单或 AI 自评分作为质量门槛。

第二轮暂停润色，从输入重新独立核验：
- 逐项重算公式、主例及全部题目，核对假设、单位、维度、正负/零和答案。
- 检查插图端点、轴比例、箭头、符号、标签、图注与正文/代码一致；
  实测手机可读性。无图/无代码时注明不适用，不为齐全强行增加。
- 实际运行每段代码，对照独立预期；存在下载时运行 prepare:downloads，
  核对同源脚本与 Notebook。不得把测试代码冒充主教程。
- 逐题核对目标、核心/可选层级、提示是否过早给答案、解答与 rubric 的充分性。
- 运行现有 review:teaching、类型、Lint、测试、Python/数学验证、构建与路由检查。
  按工作流另存证据；MA101 对比脚本先保存实际改前稿，不能使用旧版本冒充。
- 在生产服务实测修改页的桌面和移动导航、旧 hash、折叠、练习提示/答案和相邻课。
  未改渲染时不新增无意义的大量截图。报告实际覆盖、失败和限制。
- 明确校验者与方法；同一 AI 的另一轮核验仍是工具辅助，不能称为独立人工审稿。

最后报告并留待人类完成的工作：
- 规范入口、已填写简报、来源表、目标任务映射、必要改动与精确证据、测试结果。
- 原句→初学者具体困难→改句→可观察的试学任务，改写效果只写预期。
- 列出人工学科审查、中文/教学编辑、目标学生试学的责任角色、任务、证据要求与状态。
  未做就写“未开展/待人工”，不伪造审稿人、学生、分数、耗时、通过率或效果。
- 当前稿件只进入有证据支持的 pending-review/preview，technicalEvidence 指向本轮证据；
  未有人类审核证据不填 reviewEvidence，不标记 reviewed/pilot/published。
- 保留有效链接、课时/练习/section ID、旧锚点与进度；说明是否需要新修订键及理由。
- Aivora 与 AI Foundry 独立；不制作视频，不内置 AI 或调用运行时模型 API，
  不新增支付、账号、后台 CMS 或在线 Python 执行。
- 按该次任务明确的提交/推送范围交付；禁止批量删除文件或目录。
```

若任务只授权审查，则交付证据与改法，保持源码不动。若已授权实施，则继续完成必要修改与验证；不要把此模板当作额外的逐阶段许可申请。
