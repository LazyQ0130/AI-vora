### B1：四值与type

材料名str，5段int，1.5米/段float，False为尚未备齐的bool。先预测四普通值与四类型，再保存运行；不是class定义。

```python
material_name = "Festival trim"
strip_count = 5
strip_length_m = 1.5
is_ready = False
print(material_name)
print(strip_count)
print(strip_length_m)
print(is_ready)
print(type(material_name))
print(type(strip_count))
print(type(strip_length_m))
print(type(is_ready))
```

### B2：固定上限、三轮修改

段数固定5，上限固定7.5米。单段1.25米时总6.25米/True；同文件只改为1.5时总7.5米/True；再只改2.0时总10.0米/False。修改的是单段长度，比较仍总量<=同一上限。

```python
strip_count = 5
strip_length_m = 1.25
limit_m = 7.5
total_m = strip_count * strip_length_m
within_limit = total_m <= limit_m
print(total_m)
print(within_limit)
```

### B3：交互与简单f输出

Stage Blue/5/1.25三行输入，print摘要为材料名、5段、总6.25米、不超过7.5米True；另轮Stage Gold/5/1.5为总7.5米/True。第二轮是新启动。原文本str和新int/float不同，True只回答总长限制，没有自动批准/拒绝。

```python
material_name = input("Material: ")
strips_text = input("Strips: ")
length_text = input("Each m: ")
strip_count = int(strips_text)
strip_length_m = float(length_text)
limit_m = 7.5
total_m = strip_count * strip_length_m
within_limit = total_m <= limit_m
print(f"Material: {material_name}")
print(f"Strips: {strip_count}")
print(f"Total m: {total_m}")
print(f"Within {limit_m} m: {within_limit}")
```
