# 2.4起草前独立预解

2026-10-30。本轮任何比较程序执行前，先按整数大小关系与规则独立推演；后续stdout另存，不倒填。主例与参考为教学构造，本机版本先查为Python3.14.2。

| 输入表达式/条件 | 事先判断与含义 | 预期 |
| --- | --- | --- |
| 5 <= 6 | 5低于上限，包含相等但本次尚未相等 | True |
| 5 == 6 | 两值不相等 | False |
| 5 != 6 | 两值不同 | True |
| 5 < 6 | 5严格小于6 | True |
| 6 <= 6 | 刚好等于也包含 | True |
| 6 < 6 | 严格小于不包含相等 | False |
| 7 <= 6 | 超过最大值 | False |
| 7 > 6 | 严格超过 | True |
| 7 >= 6 | 大于或等于，本次大于 | True |
| 主例count5/limit6，保存<=再显示、==、!= | 保存的是bool，不改变两个整数 | 三行True、False、True |
| 合法赋值count5→比较==6，再赋值count6→比较==6 | =换当前值；==只取得相等判断 | False、True |
| 大于例7/6，依次>、>=、<= | 超过/至少达到/最多的不同问题 | True、True、False |
| 三轮同一边界文件，限6，实际5/6/7；每轮<、<=、== | 第一次低于，第二次相等，第三次高于 | 5：True/True/False；6：False/True/True；7：False/False/False |
| 等值卡count6/limit6，顺序<、<=、>、>=、==、!= | 严格不等排除边界；含等号的大小比较与相等比较包含 | 标签At capacity后六行False、True、False、True、True、False |
| 题一图书推车9册/12册，<=、==、!= | 未超容量，未恰好装满，两值不同 | True、False、True |
| 题二展板上限10幅，9/10/11幅；每轮<、<=、>= | >=判断至少达到，不专指相等或允许 | 9：True/True/False；10：False/True/True；11：False/False/True |
| 陌生题一8件/8件，<=、==、!= | 等于且未超，两值相同 | True、True、False |
| 陌生题二限15，13/15/18，<、<=、>= | 固定同一上限、只改实际值 | 13：True/True/False；15：False/True/True；18：False/False/True |
| 渐进追加完整程序 | basic的<=、保存结果后的print、==、!= | True、True、False、True |
| 主例追加type(within_limit) | 已存布尔结果类型 | 三行主例后<class 'bool'> |

最多6件包含6，对应<=；少于6件排除6，对应<。至少6件包含6，对应>=；多于6件排除6，对应>。恰好6用==，不等于6用!=。True/False只回答写出的判断，不能说<=天生表示“允许”：须先确认题目是否规定最多。

常错预判：将=当相等判断、将==当两次赋值、把<=拆成< =、只换预测未保存代码、改限制而非只改实际值、只交一轮运行。正文用合法赋值/比较对照处理概念，不用print(count=6)涉及未教调用参数的错误例，也不新增受控语法错误实验。本课新程序均应成功退出0、stderr空；旧课受控错误仍按各自契约保留。

预测限普通整数及同单位数量；不泛化自定义对象、浮点近似/跨类型/链式比较。类型名与这些简单布尔结果为稳定事实，具体错误消息若未运行不冒充实测。没有macOS实机，命令核对不能写成该平台实测。
