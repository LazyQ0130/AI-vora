## 教学编辑的实际结果

九个原 section ID 全部保留。开头只比较 A/C，规则试用后再出现 B/D 与完整四封邮件表。流程图移到规则、学习办法和三要素已有解释的位置；误判图仍在 mistakes。两题的题干、两级提示、完整参考解、错法说明和 rubric 与原稿完全相同，由注册数据摘要和测试双重核对。

| 原句或原段 | 改句或处理 | 学习困难与待观察动作 |
| --- | --- | --- |
| 开头：“这个愿望听起来简单，但要交给系统处理，就得说清它能看到什么、需要做什么、最后交回什么。” | “每封都打开看一遍，确实有点麻烦。能不能让电脑先帮你分一下，把需要的邮件留下，把垃圾邮件放到一边？” | 先让读者知道为什么想请软件帮忙，再让读者试分两封邮件 |
| 第二段：“交给系统的信息叫输入……这里的任务是分类……系统给出的判断叫输出……” | 命名移到规则与学习解释之后：“到这里，我们可以给刚才做的事起几个名字。”随后一一对应标题、分两类、交回判断 | 术语现在概括读者已见到的动作；试学时让学生指认图的三步 |
| “另一种办法是先准备许多已经分好类别的邮件示例……”后立即连续定义机器学习和模型 | 先讲 B/D 为什么判错、多看地址与订阅信息、逐条规则为什么难写全，再讲例子怎样帮助形成判断；下一段才命名机器学习、数据、模型 | 模型仍有解释，不靠删词掩盖跳步；让学生比较“人写规则”和“从例子形成判断” |
| 定义段比较 OECD/IBM 关注点，另有专家系统与推理机制结构说明、植物案例 | 机构比较从主线移至文末资料与本报告；设备诊断用“联系现象和知识、逐步排查”解释知识推理，简短命名专家系统 | 保留“AI 大于机器学习”“固定规则不排除 AI”；不要求第一课辨认知识库的内部组成。完整技术体系仍留给后续章节 |
| 应用表每行都追加一种限制，正文/图注又重复“不是模型评测” | 应用表集中展示接收的信息和所做的工作；用语音与生成的同一句通知解释检查依据为何不同。邮件构造、规则范围在首次相关位置交代，通知假设输出另作一次真实性说明 | 仍保留 B/D 反例、误删后果、检查范围有限及生成地点无依据；减少相同提醒的重复 |

校验轮由同一 Codex 辅助完成，没有充当独立人类审稿者，也未使用 AI 自评分。离开改写结论后从题设重新求解：邮件 A/C 正确、B 误拦、D 漏掉，图表和文字一致；通知里时间有来源、地点无来源。练习 A 中计算器/定时备份按题设无需 AI，照片识字已给学习方法证据，规则诊断须补充方法信息；练习 B 可以用已教的图像任务、遮挡/角度、实物与记录对照及人工更正完成。核心答案不依赖可选知识或外部课程。

从零基础顺序再读注册稿，逐段检查的教学支点为：mail-task 先有整理需求；rule-and-learning 用四个具体结果制造问题，术语在动作后出现；ai-meaning 才概括 AI；many-tasks 逐项指认任务；automation 为“信息不足”示范具体追问；mistakes/check-output 给出实际核查动作；practice 检验原三个目标。暂未发现完成这两题必须先学的算法、公式或编程内容。读者是否真的能跟上这些过渡，仍待专业编辑及试学确认。

## 学习面板与导航

桌面右栏按“本节学习目标 → 达标练习 → 本节阅读进度 → 折叠先修知识”组织。目标只有 `lesson.objectives` 一份；题目由 `assessmentMap` 与现有 exercise blocks 关联，按正文顺序去重。商品题对应目标 1、3，只有一个入口。可选进阶、可选验证放入独立折叠入口；整节可选的 PY 5.6 显示“可选挑战”，不冒充核心达标。

正文移除 ObjectiveAssessment 和重复的先修/目标卡。先修原文、补修链接和说明合并到面板的折叠区域；正文仍保留试读状态、旧修订说明及适用于原学科的术语速查。状态徽标归到元信息；零代码时间不再显示空项目，手机隐藏装饰性英文并压缩标题间距，时间仍明确为待试学校准的编辑估计，没有按字数改分钟数。

`reader-section-nav`、全部 section ID、文章目录数据及 hash 保留。桌面不再重复整套 ArticleContents。手机/平板沿用两个入口：“章节目录”和“本节导航”。后者顶部是可折叠文章目录，下面共用桌面学习面板。初版实测文章目录在面板后被推到 1000px 以下，因此前移为折叠入口；目标编号被全局列表重置隐藏的问题也已修复。没有添加顶层按钮或 UI 依赖。

点击练习、文章导航、恢复阅读位置和刷新旧 hash 共用定位逻辑：展开祖先折叠，再滚动，聚焦实际 H2/H3。Drawer 关闭后才执行定位；Escape 关闭仍回原入口。练习的 scroll-margin 调为与正文相同的 12px，配合原视口顶部留白，防止被吸顶导航盖住。旧 `#assessment-title` 也兼容：桌面定位学习面板，窄屏打开本节导航。默认平滑滚动与减少动态效果均经过实页操作。
