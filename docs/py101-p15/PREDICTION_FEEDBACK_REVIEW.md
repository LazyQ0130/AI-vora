# 十二课重点预测与诊断

仅给高价值点补「错在何处—混淆—最小核对」。一般预测可口述；改值、路径、两组输入和三轮边界的事前预期仍按题干留短对照。预测正确不等于独立完成。

| 课 | 常见错误预测/混淆 | 最小验证 |
| --- | --- | --- |
| 1.1 | 以为改文字已经进入下次执行；未保存/错目标混淆 | 加新标记、保存、同命令重跑；仍旧值再核对cwd/文件 |
| 1.2 | 电脑有run.py就能自动找到；脚本所在位置当cwd | 在固定cwd仅改变脚本路线；前后pwd，再明确cd作对照 |
| 1.3 | 运行按钮总读旧磁盘或总会保存；缓冲/磁盘/入口混淆 | 同路径外部终端控制实验，保存后同命令；核对实际整文件入口 |
| 1.4 | Version一样、Project A输出就选对环境 | 同脚本只换解释器，用现成观察工具对比executable/prefix |
| 1.5 | 保存新赋值应立即显示新值；文本/已执行状态混淆 | 只运行修改后的赋值格再显示；明确重启后全跑另验证文档充分性 |
| 1.6 | 状态0或正常文字证明环境没问题 | 保持源码/cwd/脚本参数，用同选择运行诊断；新终端复现/恢复 |
| 2.1 | 后次赋值倒改第一次输出 | 仅换后值重跑；第一次print已在更新前执行 |
| 2.2 | 3与文字3显示相同所以类型相同 | 换7与文字7，分别普通显示与type |
| 2.3 | 12 / 3 * 2得2.0，把乘法总放先 | 与12 / (3 * 2)只差括号的副本对照：8.0与2.0 |
| 2.4 | <=在等值仍假，把最多当必须少于 | 固定count=limit=6，仅将<=换<，对照True/False |
| 2.5 | 数字字符4自动是int | inspect_input同文件换7，type仍str；分步转换后才int |
| 2.6 | 普通字符串中的花括号也插值 | 副本只补f，字面{total_mass}变当前6.0，两者语法均合法 |

DIAGNOSTIC_PRE_SOLUTIONS.json在对应进程启动前保存，DIAGNOSTIC_RUNS.json为19个真实保存文件/路径/环境进程。Windows CPython3.14.2；保留命令、cwd、SHA、stdin、stdout、stderr、退出、PID与预期。公开日志只替换本机路径前缀，未造键盘回显/重排stdout。ValueError后用另一个PID合法输入恢复。
