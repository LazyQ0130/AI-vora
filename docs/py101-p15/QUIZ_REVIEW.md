# 六道Quiz的诊断复核

六ID不变，r2每题三个选项、一个正确项、三个针对性解析。没有凑四项，不以随机猜测概率宣称效度提高。题目仍检查局部认识，正式能力由24道独立代码/实验题验证。

| 课 | ID | 三种判断与验证 | 正确项 |
| --- | --- | --- | --- |
| 1.1 | file-interpreter-output | 终端被当执行者；正确文件/解释器/输出；把运行误当存盘。改标记保存重跑核对 | B |
| 1.2 | cwd-after-run | 正确保持beta；随脚本去alpha；把pwd当最近文件路径。前后pwd核对 | A |
| 1.3 | save-evidence | 重跑会读缓冲；换解释器能读缓冲；同路径存盘重跑。控制外部终端入口 | C |
| 1.4 | same-version-env | 同版本即同环境；实际路径/前缀对应目标；脚本标记即解释器身份。诊断核对 | B |
| 1.5 | saved-output-state | 正确未执行仍旧值；保存自动执行；关网页必清内核。只执行赋值格再显示 | A |
| 1.6 | normal-output-wrong-identity | 状态0即目标正确；脚本目录强选环境；同选择执行诊断核对身份 | C |

每个错误项只围绕一种可观察混淆，解析写清原因和一次可用的核对动作。正确位置分布不是教学效果证据。六道均保留：它们能快速暴露核心题操作前后的局部误解，不复刻完整开放任务。

生产浏览器逐题选择一个错误项、检查、切换正确项、检查：显示「再想一想」和该项解析，换项移除旧反馈，再显示「理解正确」。BROWSER_CHECKS.json保留当时实际DOM；其余错误项解析由源对象与结构测试核查，未冒称每个错误项都被学生选过。
