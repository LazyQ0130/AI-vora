# 1.3成稿自检与人工交接

本轮使用长期V1.0标准与现行生产流程，未将V1.1建议稿当生效标准。读取P0蓝图与P1最近审查后，先形成编辑简报、官方事实表与预解，再单课写作。没有用历史问题替代对现稿的检查。此文是AI辅助审读，不是独立人类签署。

逐段复查：四种角色先定义再进入操作；打开整个文件夹给出实际作用；保存、手动命令、官方入口分开；源码只有print和字符串；只读sys诊断不作为新语法考点。新概念限定编辑缓冲区、工作区、扩展支持和解释器选择，不重复安装章、不进入虚拟环境/依赖/模块/调试器。

未保存观察明确限定真实dirty缓冲区＋独立终端；自动保存条件不成立时要求诚实记录。官方部分入口自动保存有官方事实支持，GUI实际只验证已保存整文件入口。C类错配允许记录本机路径一致，不制造安装/PATH变化。运行结果标记不能单独证明路径，必须与位置/命令/源码合看。

练习一换为message.py起始素材，要求独立主题、改两处、加一行、运行前预测与集成终端实证，同时验收角色。练习二明确两份均已保存、同一解释器、cwd为other，唯一错配为错误同名目标；不能答成多个不可区分的原因。两题均有两级提示、四步解答、错因与替代路径、三条rubric。提示二留最终目标与运行给学生，自动测试拒绝直接泄露最终命令/结果。预解用单独声明的输出重算，并非只检验字面存在。

学习时间15–20/10–15/20–30分钟为编辑估计，共45–65分钟，未称真实用时。暂无学生完成率、成绩或教师评价。没有新增下载是因为两行文件由学生本地创建已足够，网页提供复制，不增形式资源。

待人工内容审稿：核对新手能否理解缓冲区与磁盘、解释器选择/终端命令区别、保存图标差异、只读诊断的负担与替代支持；检查正文中文节奏及练习证据表是否过重。待目标学生试学：至少Windows与macOS各实际完成两题，保留去身份化源码/预测/命令/真实输出、故障恢复依据与实际用时，评估提示二泄露程度并校准45–65分钟估时。人工或试学未完成前保持pending-review/preview。

1.4实际先修交接：能打开准确项目、保存并重跑.py、核对cwd与脚本参数，能取得实际解释器位置/版本，并独立恢复一种保存/目标错配。无需提前掌握变量、import/sys、pip或环境激活命令；新环境知识由1.4教授。本轮不制作1.4–1.6。
