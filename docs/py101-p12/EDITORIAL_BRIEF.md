# 2.5课前编辑简报

2026-10-30，正文与新程序执行前。唯一核心问题：在终端键入4，为什么程序先收到文字，怎样才能用它计算完整数量？零基础学生已完成第一章及2.1–2.4，会保存/终端完整运行、赋值、print/type、str/int/float、乘法/单位及比较。第一次接触input，不重新安装Python。章名以curriculum为准：变量、基本类型、表达式与输入输出。

主例每件需3个标签，物品名label与标签个数分清；先纯文字输入Box A，再count_text/str观察，int单独转换，最后组合Box A/4及Tool B/2两轮。单件质量千克用float，1.5与2.25分别乘两件。案例为教学构造，不是学生数据。

新语法第一次出现先说用途、执行位置与观察结果。input提示写stdout无自动换行，终端键入通常回显，print后续显示，shell提示不属于程序输出；说明性text框逐行标注，不伪装原始日志。自动stdin真实进程与GUI终端观察分别留证，禁止补造键盘回显。

题一参考活动入场牌每组5张，用Hall C/3、Hall D/6；题二参考4段绳的总米数1.25/2.5，副本oops后重启0.75；学生另选情境/名称/数据。两级提示只指思路与组织步骤，不代填输入或完整源码。参考完整代码以现有verification节折叠，解释答案说明每行、单位、错因与合理替代；核心任务不依赖未教语法。

不教if/try/except/循环/isdigit/eval/bool(input)/f-string/函数/参数/文件/API，不先嵌套int(input)，不用int(float(...))改变完整件数要求。错误只在新建受控副本，先留真实回溯再重启，不改PATH或重装。网站只展示教材/临时笔记，本地终端才交互。
